## 命題1：繁殖保障の変化は先行し得る。しかしその遺伝的進化は花投資低下の必要条件ではない

論理的な必要条件の仮説は「投資低下 `I↓` が起これば必ず `A` が遺伝的に変化した」であり、反例には `A` が遺伝的に**固定された介入群で投資低下が生じる**ことを示せばよい。

### 1a. 先行という観測事実の範囲

[別の時系列登録・確認コホート](CHAPTER2_1005_CONFIRMATORY_RESULT_20261006.md)では、遅延自殖・直接A費用0.5・突然変異0.01・初期保証0.5というモデル設定で、閾値0.05・20連続センサス・5センサス近同時窓に対して **A-first 51/64 = 0.796875**、独立訪花者履歴bootstrap95 **[0.6875,0.890625]**。閾値0.025/0.05/0.10の記述的感度では48/51/59件。これは「**観察した保証表現型が先に閾値を越えた**」という意味で、保証への選択が投資への選択より先に開始したことや、A-firstがI減少を引き起こしたことの証明ではない。

### 1c. 静的機構は説明補助、動的媒介の証明ではない

生殖式で訪花者が完全不在の場合、外交配の雌雄機能 `F=P=0`、自己由来の生存可能子が正ならば、`W=S=a(1−δ) O`（優先自殖でも花粉0で同じ）。胚珠資源 `O=b exp(−c_I I²−c_A A²)` に対して、**正のa、δ<1、固定aと他形質のもと**
```
∂ log W / ∂I = −2 c_I I .
```
これは「花粉がないとき、投資の資源費用はなお負の局所勾配を生む」という**モデル内の厳密な局所式**。A=0やδ=1で`W=0`ならlog微分は定義できない。送粉者がある近/遠環境について、これだけで1,000期の終点差を導出できない。男性機能・他の個体への花粉サービスを落として「唯一の進化経路」とはしない。

[別の固定状態勾配](../data/results/chapter2_assurance_gradient_components_20261006.json)は、Aを0.25→0.75に介入したときの**I勾配の変化**（snapshot400でより強くnearで負）であって、A固定の局所I勾配そのものや遺伝的な媒介率とは別。特定のnear`+0.58`・far`−0.70`を論文に載せるには**ソース・適応度定義・規格化・年を一致させる追加照合が必要**。ここでは登録資料で確認できた符号と解釈のみ採用する。

## 命題2：無突然変異・無移入の支持は一方向に閉じる。ただし形質順序への波及は別の実験上の問い

### 2a. 局所座位の支持非増大：証明

各座位 `ℓ` に残る**値として区別したアレル集合**を `S_{t,ℓ}` とする。新しいアレル突然変異・外部移入がなく、既存生存個体もアレルを新規作成せず、繁殖子の両コピーは母父のいずれかの相同コピーからメンデル抽選される。そのとき
```
S_{t+1,ℓ} ⊆ S_{t,ℓ} ⊆ S_{0,ℓ}.
```
形質が二アレルの平均 `z=(a+b)/2` なら、`min(S_0) ≤ z_t ≤ max(S_0)`。初期平均 `z̄_0` の下限・上限変化は `z̄_0−min(S_0)` と `max(S_0)−z̄_0`。**一般の集合幅 `max−min` を勝手に半幅hとは呼ばない**。初期形質平均が0.5、アレル支持が`0.5±h`に対称な場合にだけ`|Δ z̄| ≤ h`。

ある指定した**新しい**追加低下 `Ī ≤ Ī_0−0.05` を目標とする際、現時点の全Iアレル下限が `Ī_0−0.05` を**厳密に上回れば**、その後の出生だけでは新たな到達は不可能。支持が残るだけでは到達を保証しない。また既に一度目標を達成した軌跡まで「低下不能」とは呼ばない。完全個体群絶滅時の平均は欠測であって0ではない。

### 2b. 支持消失と選択方向の非一致：元2,304の**別**コホート

[元の生物学的支援結果S14](CHAPTER2_Q3_FINITE_GENETIC_ACCESS_AND_REALIZATION_20261015.md)は**I座位の新突然変異0、移入0**の18セル×128再利用乱数ID＝2,304本。単一アレルへの完全固定前に、0.05追加I低下のアクセスが閉じたのは**703本**。ただし**そのうち1本は既に以前の目標イベント達成済み**なので、「未達だったのにその後到達不能になった」は**702本**。さらに完全固定に一致して閉じた535本と合わせ、初回アクセス除外の記録は1,238本。

その**同じ1,238件の初回アクセス除外遷移**のうち315件では、低Iを可能にするアレルの**条件付き期待・親の繁殖重み付き頻度変化が正**だった一方、実際の有限出生子は必要コピーを保持しなかった。これは**すでに失った遷移で条件づけた315/1,238**であり、無条件な「正の選択下での喪失率」でも、純粋な遺伝的浮動の割合でもない。**703と315は別分母・別条件であり、一方はもう一方の部分集合として定義されない**。

## 論文化の論理順序

1. **Counterexample:** 特定のA-first出現を示したのち、A=0.5固定でもIが低補充側でさらに減少するQ1介入を示す。新8×8原本も4設定すべてで負の交差CI。必要性の否定は強いが、Aの存在や自殖を取り除く反例ではない。
2. **Theorem:** 新突然変異・移入のないメンデル遺伝の支持集合単調性を提示する。**これはモデル機構の性質**であり、自然の遺伝子変異率に関する経験的定理ではない。
3. **Source-based empirical consequences:** Iアレルの支持が閉じる頻度703（目標前702）と、正の条件付き期待頻度変化でも失われた315/1,238を別の観測量として提示する。
4. **Boundary/sensitivity:** A初期半幅の変更で、双方到達可能なd=0.025ですら順序スコアが負から正へ反転した。ただし探索的感度であり、その媒介は未同定。
5. **Prediction vs finite realization:** 3/32・2/32と会計恒等式を述べる。有限過程での応答実現と、密度モデルの予測を区別。**四つのデータ群の分母や実験条件を足し合わせない。**

**最終的に言えること：** Aの遺伝的進化は、送粉者補充差に伴うIの低下の必要条件ではない。しかし、Aの変化と植物個体群が保持する遺伝的支持は、投資応答の大きさ、到達可能性、順序と有限の実現の関係を変える。**その変化を一つの媒介機構に還元することは、現行のQ1/Q2/Q3/Q4では未証明**。
