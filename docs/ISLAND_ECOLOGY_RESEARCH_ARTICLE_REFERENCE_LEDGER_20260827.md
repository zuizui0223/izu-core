## Hygiene decisions

### Lord (2015)

`Lord 2015` remains in the source-audited island-syndrome literature matrix as a legitimate counterexample/limit source for the proposition that source flora and climate can confound apparent island syndromes. It is **not cited in the current active manuscript**, so it is excluded from the active reference list. This resolves the previous uncited-reference problem without discarding the source from repository provenance.

### Méndez (2025)

`Méndez 2025` remains in the source-audited matrix as commentary relevant to separating filtering from in-situ flower-size evolution. It is **not cited in the current active manuscript**, so it is excluded from the active reference list. This likewise resolves the previous uncited-reference problem while retaining the source as background provenance.
