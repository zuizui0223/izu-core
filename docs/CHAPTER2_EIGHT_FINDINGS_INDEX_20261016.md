# Chapter 2 — 発見カード8件と証拠の序列（2026-10-16）

> **文書の役割**：izu-core Model 3の成果を「約60本の解析・多数の検証ファイル」から8つの科学的メッセージへ整理する**編集用索引**。新しい実験、原資料の再生成、独立再現、メタ解析、優先権認定ではない。原本データ、凍結デザイン、S1–S33、失敗・未決はすべて元の場所に保持する。対象はCh2の合成モデルであり、実際の伊豆諸島の歴史的因果を推定したものではない。

## 冒頭の一文（単一Letterの問い）

**送粉制約は繁殖保障と花への投資をそれぞれ変化させ得るが、その変化の時間順序、有限集団での実現、将来の集団存続はどの程度一致するのか。**

**既に答えたこと：** 一部の選択・進化応答は事前凍結介入で確認された。遺伝的な到達可能性の喪失、条件付き決定論と有限実現の不一致も別々に数値・原ゲノムで確認された。**未解明：** 3/32・2/32の順序不一致を生んだ原因ごとの寄与、Q1→Q4の一続きの媒介、自然島嶼での普遍性。

## 論文に採用する発見カード

### F1 — 花への投資の低下は、繁殖保障能力の進化を必要としない
- **一文**：低い訪花者補充のもと、保証能力Aの進化を固定しても投資Iは減り得る。
- **支える解析**：[S1 原本・4設定](../data/results/chapter2_assurance_generality_20261006.json)、[独立固定A確認](CHAPTER2_1005_CONFIRMATORY_RESULT_20261006.md)、[固定状態の母性・父性リターン](MODEL3_FIXEDPLANT_RETURNS_RESULTS_20261005.md)。
- **確実度**：**確認**。4/4の事前条件を満たす。独立単位は64訪花履歴、各履歴の8反復は入れ子。
- **限界**：固定したのは**Aの進化**（能力は0.5）で、自殖自体は可能。普遍的な「自殖と花形質の無関係」を示さない。

### F2 — 繁殖保障能力の進化は、環境間の花投資の差を圧縮し得る
- **一文**：Aを進化可能にすると、低・高訪花者補充の間の最終I差が縮小した。
- **支える解析**：[S1 4設定の相互作用](../data/results/chapter2_assurance_generality_20261006.json) +0.1007–+0.2200、[腕別算術分解](../data/results/chapter2_assurance_attenuation_decomposition_20261006.json)、[自殖・送粉のカップリング監査](CHAPTER2_ASSURANCE_COUPLING_SCOPE_20261015.md)。
- **確実度**：**確認**（モデル条件下、更新1000時点）。近側への追加投資低下の局在78–90%は**探索的な算術分解**。
- **限界**：近側でも外交配受精は約22%、遠側約1%で、双方花粉制限下。高供給側を「受粉十分な本土」と呼ばない。算術分解を因果寄与率と読まない。

### F3 — 観察された先行順序は、後続形質変化の必要条件ではない
- **一文**：遅延自殖・保証コストありではA先行が51/64履歴に反復したが、A進化を止めてもI低下は起きた。
- **支える解析**：[独立順序確認](CHAPTER2_1005_CONFIRMATORY_RESULT_20261006.md)、[4設定の固定A介入](../data/results/chapter2_assurance_generality_20261006.json)。
- **確実度**：**確認**（ただし**異なる登録実験を論理的に接続**している）。
- **限界**：先行自殖ではA先行30/64で多数派を確認できず。イベント閾値・持続窓に依存し、全繁殖設定での普遍的A先行を否定する。

### F4 — 表現型が同じでも、隠れたアレルの支持幅は応答順序を変え得る
- **一文**：初期平均表現型を揃えてA対立遺伝子の半幅を0.046875→0.078125とした対照で、六分類のA-firstとI-firstの差Dは+0.669271変化。Aイベント発生率の増分は+0.033854だった。
- **支える解析**：[S8 遺伝的アクセス境界](../data/results/four_question_resolution_20261011/)、[S20 既存768対応ペアの再集計](CHAPTER2_GENETIC_ACCESS_PAIRED_CLOCK_20261014.md)、[元の1,536履歴の凍結集計](../data/results/genetic_access_pilot_20261014/FROZEN_EXPLORATORY_READOUT.json)。
- **確実度**：S8の登録された**条件付き境界**、S20の**探索的・原本再集計**。原創始者遺伝子型は2つ。
- **限界**：半幅操作は到達可能な支持範囲、分散、閾値幾何を同時に変える。「変異量だけが順序を決めた」とは書けない。S20では両腕検出の742対応ペアでAの開始時刻差が平均−47.3更新。これは**閾値を持続して達成する最初の時刻**で、選択開始の時刻ではない。

### F5 — 初期状態は予測情報を持つが、同一初期状態の実現を一意に決めない
- **一文**：元の2,304履歴は18個の初期（創始者×送粉環境）状態に分かれ、同一群でも六分類結果が分岐した。元の初期投資の期待遺伝応答を入れると単純モデルの六分類対数損失は改善するが、柔軟な対照には一貫して優越しない。
- **支える解析**：[S18 識別可能性](CHAPTER2_INITIAL_CLOCK_IDENTIFIABILITY_20261013.md)、[両軸holdout](CHAPTER2_INITIAL_CLOCK_TWO_AXIS_CV_20261013.md)、[S19 応答開始と到達順序](CHAPTER2_EXISTING_RESPONSE_TIMING_RESULTS_20261013.md)。
- **確実度**：**探索的な予測限界・反証結果**。18群の事後最多クラス正答率は**1,117/2,304 = 48.48%**（標本内、六分類）。二軸holdoutの六分類対数損失：生態＋初期I分散1.47931、＋t0 Price応答1.42169、柔軟な生態・遺伝対照1.41659。
- **限界**：**「49%が普遍的上限」「進化はほぼ予測不可能」は不可**。S18は既に初期I遺伝分散を使用し、初期Aの表現型分散・期待応答は全18群で0、分離潜在力も一定。同じデータに同じ分散を足しても区別できる初期群は増えない。異なるAアクセス状態を含む新しい創始者・送粉文脈の、結果を見ない予測検証が必要。F4の実験でF5の未説明部分の割合を特定したことにはならない。

### F6 — 集団が存続しても、予測された二形質の応答順序は再現されず、特定の遺伝的経路は閉じ得る
- **一文**：条件付き決定論がA-firstと分類する2つの低供給・機能一致創始者条件で、元の有限ABMは3/32、2/32しかA-firstにならず、全64履歴が更新200まで占有。他の元の遺伝子型系列では、特定の追加I低下に必要なアレル集合が全固定前に失われ得た。
- **支える解析**：[S7 元の320経路](CHAPTER2_Q3_FINITE_GENETIC_ACCESS_AND_REALIZATION_20261015.md)、[検証済み元ゲノムと主図](CHAPTER2_Q3_ATOM_MAIN_FIGURE_20261016.md)、[S14 2,304系のアクセス・親子伝達](CHAPTER2_Q3_SELECTION_REALIZATION_SOURCE_MAP_20261015.md)。
- **確実度**：**元ゲノムからの再読込み・条件付き数値比較**。別の2,304履歴で703履歴に全固定前の指定応答アクセス喪失、同じ2,304履歴の1,238初回喪失遷移中315で**条件付き期待アレル頻度上昇**と実際のコピー消失が併存。
- **限界**：密度閉包はABMの厳密な確率的期待値ではなく、差をドリフトの寄与率にできない。315/1,238は**消失を選んで条件付けた遷移**で、全履歴で有利アレルが失われる確率ではない。703系は3/32の原因の媒介分析ではない。両創始者でIの平均は**実際に低下**した（「進化が全く起きない」は誤り）。

### F7 — 存続の帰結は、繁殖準備状態・容量・種子生存処理に条件づく
- **一文**：自然に進化した順序そのものの存続利益は未同定だが、実験で変えたA進化可能性、初期A平均、K/種子生存率には限定的な占有効果が確認された。
- **支える解析**：[S33 独立32履歴](CHAPTER2_ISLAND_PERSISTENCE_PROMOTION_DECISION_20261008.md)（総合交互作用+10.84パーセントポイント）、[S3 固定B48でのK介入](CHAPTER2_TIMED_SELF_VIABILITY_INDEPENDENT_RESULT_20261010.md)（+0.0077457）、[S10 初期A平均等化](CHAPTER2_INITIAL_ASSURANCE_MEAN_RESULTS_20261013.md)（寄与+0.03125/+0.04492）、[S16/S22 親重み対照](CHAPTER2_UNIFIED_EL_SUPPORTING_INFORMATION_20261010.md)。
- **確実度**：**設定を限定した複数の登録介入**。S33のA進化モードは過去400更新だけでなく**将来80更新にも継続**。S16/S22の親重み主解析は未決。
- **限界**：「順序**ではなく**状態が効く」という排他的・因果的な結論は未支持。自然なA-firstの存続救済も証明していない。互換でない各実験のパーセントポイントを合算しない。

### F8 — 花投資の集団存続上の符号は時間・密度で反転し得る
- **一文**：遺伝進化を止めた固定クローン／固定訪花者の人口Markov計算では、同じ全個体I=.34→.36操作が初期に占有を上げても、K8・予算6では更新8から占有差が負に転じ、K48では更新1–80で正のままだった。
- **支える解析**：[Q4固定クローンの時刻符号](CHAPTER2_Q4_CLONAL_INVESTMENT_TIME_SIGN_20261010.md)、[S12 最終占有と累積時間](CHAPTER2_UNIFIED_EL_SUPPORTING_INFORMATION_20261010.md)。
- **確実度**：**指定モデルの数値的に厳密な人口遷移計算／探索的パラメータ設定**。K8・予算6の更新80差は**−0.0466パーセントポイント**、K48は**+0.4220パーセントポイント**。
- **限界**：全群に同じIを固定した比較で、**進化した花投資の効果ではない**。資源予算8では同じ向きにならず、一般的な進化的自殺の証拠ではない。単一Letterの本論ではなく補遺・博士論文向け。

## F4×F5を結ぶときの次の決定的テスト（**計画のみ**）

S18の48.48%は、初期状態18群内の結果を事後に使った**標本内の決定的最多クラス正答率**。既に初期I遺伝分散は使われている。Aの初期表現型分散・期待応答と潜在分離分散は18群を通じて不変。よって**「S18に分散を追加すれば48.48%が上昇する」は成立しない**。同じ18群だけなら、初期状態に定数または既知の2創始者ラベルを追加しても観測プロフィール数は増えない。

真に検証したいのは**未知の創始者遺伝子型に対する六分類の確率予測**。新しい、互いに区別できるA半幅・I支持集合・共保有配分を持つ創始者群と独立乱数履歴を事前固定し、(1) 生態のみ、(2) 生態＋全初期遺伝子型特徴、(3) 生態＋遺伝アクセス遅延予測＋実現後の応答モデル、(4) 同程度以上の柔軟性を持つ生態/遺伝相互作用の帰無対照を、**共通の六分類対数損失**と校正で比較する。leave-one-founder-outとholdout seedを両方守る。A-only/I-only/tie/neitherを除いて正答率だけを高めない。

**検証できる主張：** 隠れた遺伝アクセス情報が、単なる生態環境・初期I分散を超えて、新しい創始者の応答順序の**確率予測**を改善するか。**現在は未検証**であり、S20の差をS18の未説明率の因果寄与にしない。
