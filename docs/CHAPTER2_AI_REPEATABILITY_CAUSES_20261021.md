## 結論

1. 同じ試行群の12設定×初期状態集計でAの反復内終点分散はIより小さい。しかし、これは「Aへの選択が一貫して強い」と同義ではない。

3. 別途保存された同設定・同履歴・同反復のnear/farの2経路では、AはIより早く単一アレルになった。固定が関わる直接の例だが、全12,288経路の原因比率や普遍的なA先行ではない。
4. Iには履歴に対応した構造と、同じ履歴内の反復変動が両方ある。後者を純粋な遺伝的浮動や「自然の一つの島の偶然の割合」と呼ばない。
5. 選択の一貫性・強さから固定と終点収束へ至る媒介を、同じ反復群の時系列で検証する資料は不足する。選択と固定は競合する説明とは限らず、一貫した選択が固定を促すこともありうる。

## 3. 選択が一貫して強いことは示せるか

モデル式上、コストなし・花粉割引なしの遅延自殖ではAの局所的な希少変異体利益は `(1-delta)*(1-q)` に比例し、他殖不足下で非負。これは**符号の制約**で、強さ、変異量、固定速度、有限集団の平均変化を保証しない。強い近交弱勢や小さい不足なら利益は小さい。先行自殖・直接コスト・花粉割引を含む条件には、この符号保証を一般には適用できない。[選択式の記録](protocols/CHAPTER2_TWO_THRESHOLD_PRIVATE_SOCIAL_RECOVERY_SYNTHESIS_20261018.md)。

別の保存済み48セルPrice恒等式検査は、選択方向の判定にはそのまま使えない。元の生成コードで `founder_mean` は抽出・格子化前の指定平均であり、実際の遷移前平均 `mass @ traits` は出力に保存されていない。そのため `exact_next_mean - founder_mean` を期待応答と解釈する集計は採用しなかった。既存恒等式の成立判定自体を否定するものではない。仮に実際の期待応答が読めても、多形質の遺伝的関連を含む平均変化は局所選択勾配や選択強度と同じではない。[原本](../data/results/model3_repair_price_recheck_20261004.json)、[生成コード](../scripts/audit_model3_multivariate_price.py)。

また、51/64対30/64のA先行率は閾値到達の順序であり、利益の私的性だけを変更した介入ではない。「直接の補償だから選択が一貫する」の因果検証としては使わない。

## 4. 花は履歴と偶然のどちらに左右されるか

今回、同一のA/I終点群に対し、各設定・初期状態・armごとに、総偏差平方和を履歴平均間と履歴内に厳密分割した。独立の因果的分散成分推定ではなく、有限標本の記述的分割である。履歴平均間にも4反復の標本変動が含まれ、履歴をまたいで同じ反復seedラベルを用いる。

中央初期状態far側で、Iの履歴内平方和／総平方和は遅延対照 .616、花粉割引 .699、保証コスト .563、先行自殖 .738。**同じ履歴でも終点が分かれることは直接確認できる。** Aにも履歴内変動があり、対応割合は .740/.658/.684/.749。Aの絶対分散が小さいことと、Aの変動に占める履歴内割合が小さいことは別である。

別の固定Aの24,576-case bridgeでは、既存の事後分散成分解析が通常条件の単一路径ICC .170、8反復平均の信頼性 .621、大集団で .370/.825を報告している。通常条件の残差割合 .830は、このモデル・標本・分解での反復残差であり、自然の一つの島の花の83%が偶然だという推定ではない。反復残差には標本化、継承、履歴との動的相互作用等が含まれる。固定Aのこの集計はA/Iの進化比較には使えない。[元の分解](CHAPTER2_HISTORY_DEMOGRAPHY_REPEATABILITY_AUDIT_20261003.md)。今回この旧分解の原本全シャードは再計算していない。

## 5. 160×160保存データで四つの原因に分解できるか

登録160×160は創始者と訪花者履歴の交差だが、**各創始者×履歴×方針×資源条件に独立な同条件反復がない**。したがって、創始者平均差、履歴平均差、残りの差は記述できても、残りを「創始者×履歴の相互作用」と「有限集団の偶然」に別々に識別できない。方針や資源の異なるarmを同条件反復として利用しない。[設計と制約](CHAPTER2_CONFIRM160_RESULTS_20261019.md)。

解析式 `Y_fh = mu + F_f + H_h + FH_fh + e_fh` では、一セル一観測なので `FH_fh` と `e_fh` は観測上分離不能。二方向分散分析の残差を純粋な偶然と呼ばない。追加仮定で数を出せてもデータだけによる識別ではない。

今後の解析手順を固定することは有益だが、既に結果を見た保存データが新しい事前確認実験になるわけではない。既知の結果・探索履歴を記録する必要がある。現状では「四源の確認的分解」を実行したとは報告しない。
