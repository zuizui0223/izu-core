## 結論の中心

**計算の再現、モデル内の因果操作、自然界の説明は別々に判定する。** 同じ原本・同じ生殖式に基づく複数の検算が一致しても、独立した生物学的証拠が増えたことにはならない。今回の修正は検証漏れ・入力照合・出力保護を中心とし、凍結された生物学的作用素、設計、保存結果を変更しない。

## 循環を三種類に分ける

1. **世代間のフィードバック**：現在の遺伝子型→生殖→次世代の遺伝子型。時間順序のある生物過程であり、これ自体は循環論法ではない。現在の訪花者履歴は外生であり、花縮小→訪花者消失という個体群フィードバックは実装されていない。
2. **実装の依存関係**：`density`と`tensor_density`の依存は関数内の遅延読み込みを含む。単純なファイル依存グラフの閉路だけで、実行時の無限再帰・起動失敗と判定しない。
3. **証拠の循環**：原本を同じ作用素で再演する、同じ保存状態から花粉アッセイを計算する、同じ結果を別の図で描く。この一致は再現性・会計・整合性を支えるが、自然界の独立した機構検証にはならない。

ハッシュ一致は「どの入力・ソースを使ったか」の条件である。完全な条件集合、重複の不在、有限値、軸の対応、式の妥当性は別に検証する。今回、正しいハッシュ付きの小型合成例でも、欠落や重複を受け入れる検証器があることを再現した。これは実際の保存アーカイブが壊れているという主張ではない。

## 古い集団と新しい集団の扱い

古い固定創始者の結果は、その創始者・訪花履歴・設定に条件づけた結果として残す。新しい創始者群は、その条件外で同じ主張が維持されるかを調べる別の実験である。結果の好ましさを採用基準にしない。

差の原因を断言するには、創始者ゲノム、訪花履歴、人口学的乱数、初期A/I、変異・遺伝・停止条件、集計単位を照合する必要がある。今回のソースレビューだけでは、結果差を一つの原因に分解したとは言えない。登録された新コホートの判定を、旧結果を救うように変更しない。
