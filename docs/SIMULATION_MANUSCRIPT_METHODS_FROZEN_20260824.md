# Simulation manuscript Methods — frozen 2026-08-24

## Study design and inferential boundary

We treated the project as a **simulation study with qualitative external island-system challenges**. The primary analysis asks which response-state classes are generated by an already-frozen island pollination ABM, which implemented mechanism axes alter those states, and how informative an observed state is about its generating mechanism. External island systems were not used to estimate parameters, choose random seeds, add mechanisms, define post-hoc numerical targets, or rescue failed model projections.

All manuscript-level numerical claims are traceable through `data/design/simulation_manuscript_methods_traceability.json`. The canonical study route is `data/design/simulation_study_mainline_20260824.json`.

## Frozen model architecture

The ABM represents plant lineages in a standardized functional matching-trait space exposed to a common island-associated change in pollinator functional opportunity. Lineages retain pre-existing differences in initial functional position and, depending on the experimental layer, can also differ in adjustment, local network support, partner effectiveness and autonomous reproductive assurance. The standardized functional trait is an abstract model coordinate; it is not assigned post hoc to tube length, nectar guide, colour, FDQ or any other single empirical floral trait.

The common opportunity perturbation and fixed-visit-budget core were inherited from the pre-existing v4 implementation. No empirical island-system values were loaded as calibration targets in the v11–v14 mechanism experiments used here.

## Downstream factorial and branch allocation

The v11 factorial independently toggled four downstream modifiers: local support, dependency heterogeneity, assurance responsiveness and partner effectiveness. For every factor configuration, lineage responses were compared across matched mainland-like and oceanic-like endpoints over the same declared saturation envelope. We recorded pooled positive/negative response counts, mixed-sign run frequency, branching balance and paired lineage sign changes under drop-one ablations.

The key purpose of v11 was not to fit observed island frequencies. It asked whether two-sided response branching persisted when downstream modifiers were removed and which modifiers changed branch identity conditional on branching already being present.

## Residual branch-generator ablation

After the four v11 downstream modifiers were fixed OFF, v12 tested three retained lineage-level residual factors: initial trait-position heterogeneity, trait-adjustment heterogeneity and assurance-ceiling heterogeneity. The primary state criterion was **within-run mixed-sign branching**, defined by the presence of both positive and negative lineage responses within the same matched stochastic run. Mean within-run branching balance provided a complementary measure of two-sidedness.

A factor was considered necessary for branching within this declared residual gate if its frozen removal eliminated mixed-sign runs and reduced within-run branching balance to zero while other single-factor removals retained branching.

## Independent replication of the minimal branch generator

Because network-context and assurance conclusions already had independently seeded robustness blocks, we prespecified one additional independent v12 block for the central branch-generator claim. Before execution, we froze seed `90260825`, four replicates per saturation, 24 lineages, 120 steps and saturations 1, 2 and 3. External targets and empirical inputs were absent.

The decision rule was fixed before inspection. The result was classified as `replicated_minimal_generator` only if the independent full residual block contained mixed-sign branching, initial-trait heterogeneity OFF eliminated mixed-sign branching and within-run branching balance, and at least one other single residual ablation retained branching. If the full independent block had contained no branching, the outcome would have been recorded as inconclusive; if initial-trait heterogeneity OFF had retained mixed-sign branching, the minimal-generator claim would have been contradicted.

The first workflow attempt failed before simulation execution because the wrapper import path was invalid. Only the import path was repaired; the frozen seed and design were unchanged. The first successfully executed scientific result was retained. No additional seed search was performed.

## Network-context buffering capability

To test strong buffering by local support independently of autonomous assurance, the network-context experiment compared support OFF and support ON using the same underlying global opportunity networks while assurance ceiling and assurance responsiveness were disabled. We restricted sign-rescue evaluation to lineages in which global opportunity declined and the support-OFF reproductive response was negative.

A **sign rescue** occurred when support ON moved the matched reproductive response to the zero boundary or above. A **magnitude rescue** occurred when support ON made the decline less negative without necessarily crossing zero. A **worsening** occurred when support ON made an eligible decline more negative. The presence of both sign rescue and worsening precludes interpreting local support as a monotonic or universal buffer.

The primary claim uses the independently seeded robustness block; the earlier block is retained as supporting replication rather than pooled as an enlarged sample selected after inspection.

## Autonomous assurance robustness

The assurance experiment compared otherwise matched simulations with the autonomous-assurance route enabled or disabled while preserving identical upstream effective-service changes. Strong sign buffering required a negative effective-service response to coexist with a non-negative reproductive response attributable to assurance. Magnitude attenuation required only a less negative reproductive response.

Robustness was assessed in an independent frozen block and a broadened local-support envelope. The current manuscript reports strong sign rescue only if it replicated; isolated non-replicating sign rescues are retained as historical frozen outcomes but are not promoted to the stable mechanism claim.

## State separability and inverse identification

We distinguished **forward state generation** from **inverse mechanism identification**. Diagnostic sensitivity, false-positive rate and specificity were calculated directly from frozen intervention frequencies rather than by fitting a classifier to external island labels.

For initial trait-position heterogeneity, mixed-sign branching was treated as a positive diagnostic and heterogeneity-OFF runs as the negative intervention. Same-direction response was separately evaluated as a candidate indicator of trait uniformity. For buffering, network-context sign rescue was compared against the tested assurance route, and magnitude attenuation through assurance was compared against attenuation generated by network context.

These diagnostics quantify asymmetry within the implemented model family only; they are not empirical estimates of diagnostic performance across natural islands.

## External island-system state challenge

A global literature screen was external to parameter selection. Fifty-four geographic/system units were retained in the screening denominator. Thirteen systems met the strict state-challenge admission criteria. Their observed states were assigned using source-locked evidence before comparison with the already-frozen state vocabulary.

The 13 strict systems comprise three branching cases, six same-direction propagation cases, two buffering/alternative cases, one reproductive-axis-decoupling constraint and one retained falsification. The 11 generative challenges were scored only for qualitative state-class coverage or sign-class compatibility. No numerical distance-to-model score, posterior fit or parameter optimization was performed.

Puerto Rico–Mona *Guaiacum* was not collapsed into a generic buffer label because its reproductive axes decouple. Dominica *Heliconia* was retained as a failed frozen signed-position mapping and was not remapped after inspection.

## Falsification rules

The primary claims were paired with explicit failure conditions in `data/results/simulation_manuscript_falsification_table_frozen.json`. The minimal branch-generator claim fails if mixed-sign branching survives the initial-trait-heterogeneity OFF intervention. The universal network-buffer claim is rejected by any matched worsening. The robust assurance sign-buffer claim is rejected when sign rescue does not replicate in the declared robustness blocks. The Dominica mapping remains failed. A future predeclared external state outside every frozen state class must be logged as a state-space miss before model extension.
