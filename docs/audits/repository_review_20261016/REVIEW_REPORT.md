## 科学的な論理・矛盾・循環

詳しい対照表は[論理・矛盾・循環の整理](../../REPOSITORY_REVIEW_LOGIC_20261016.md)。

1. **仮定と帰結**：資源費用、近交弱勢、受粉関数は入力仮定。A上昇・I低下は基本遺伝過程に直接指定していないが、帰結はその利益・費用の仮定に条件づけられる。
2. **異なる比較量**：固定Aと進化Aの差、初期値からの変化、現在状態の局所勾配、長期終点の差は別々の量。符号の相違だけでは矛盾とも機構の証明とも言えない。
3. **決定論対確率論**：有限の自己花粉除外など作用素にも差がある。「全て浮動の効果」という説明は不適切。
4. **独立性**：同じ保存状態のアッセイ、同じ式の再演、同じ結果からの複数図は別々の独立実験ではない。遺伝履歴・訪花履歴・入れ子反復の分母を混ぜない。
5. **世代間フィードバック**：遺伝子型→生殖→次世代は意図された過程。同時刻の循環した更新は見つからなかった。花が訪花者個体群の次期到着・消失を変える機構は実装されていない。
6. **旧集団と新集団**：創始者条件付きの旧結果と、別創始者群の結果を両方残す。好ましい結果を採用するのでなく、事前の設計・推論対象に従う。このレビューは差の一意な原因を新しく同定したものではない。
