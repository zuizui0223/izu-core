# Visitor number, functional redundancy and matching-optimum composition (2026-10-10)

**Status: new exploratory source-model falsifier on PR #452, not a confirmatory biological experiment.** The already exposed within-source matched-state intervention found 176/505 conflict flips when both actual and replacement states held *visitor type count at four*. That is a useful proof of composition dependence for the original hand-selected reference assemblage, but it does not identify whether the number of types, trait-optimum locations, per-type breadth, efficacy or encounter intensity is responsible for more general differences. This add-on tests a narrow, mathematically falsifiable subproblem rather than upgrading those 505 correlated years to independent evidence.

## Factorial intervention

Hold Model3 original reproductive kernel, one fixed eight-adult diploid parental state (N=K=8), B=48, delayed selfing, ovule budget 8, pollen and other parameters fixed. Repeat for a monomorphic starting state and an explicitly synthetic standing-variation diploid state. These are **two designed states, not biological population samples**.

| Visitor arm | IDs | Unique trait optima | Matched optima |
|---|---:|---:|---|
| `two_unique` | 2 | 2 | 0.15, 0.55 |
| `four_clones` | 4 | 2 | 0.15, 0.15, 0.55, 0.55 |
| `four_distinct` | 4 | 4 | 0.15, 0.35, 0.55, 0.75 |
| `four_shifted` | 4 | 4 | 0.35, 0.55, 0.75, 0.95 |

Each visitor type has source-model breadth 0.18 and effectiveness 1. The four-arm comparison is crossed with `activity_mode=fixed` versus `count_scaled`, holding the source activity constant within each row of the cross. The reference visitor count is four in both laws. Every intervention runs through `ledger_stats` (unchanged Model3 `reproduce_kb`) and the original mixed-genotype focal β/group Γ_seed evaluator with step 0.005 and deadband 0.02. **The comparison never alters reproduction in a simulated future, runs no histories and does not observe genotype selection or persistence.**

## Exact falsification predicted from source code

Under `fixed` activity, **doubling every visitor type as a perfect duplicate cannot change the reproductive ledger**: total affinity across duplicated channels doubles, each plant's channel share is halved, `affinity.mean(axis=1)` is unchanged, and each identical recipient share contributes twice at half the weight. Thus pollen transfer, maternal/outcross/self viable seeds, β and Γ_seed all remain unchanged (up to numerical roundoff).

This is an *exact model-identity negative control*, not a claim that ecological species richness can never matter. The nominal number of visitor IDs increases 2→4 while the **number of independent functional optima remains two**.

When `activity_mode=count_scaled`, changing 2→4 visitor IDs changes the source encounter activity multiplier from 2/4 to 4/4. Duplicate visitors can then change pollen export even though there are no new functional optima. **An apparent visitor-richness effect may therefore be generated by the activity law itself.**

At *fixed ID count four*, replacing cloned optima with four distinct ones or shifting all four optima tests a direct **functional-composition intervention** holding type count, breadth, effectiveness, parental genotype, N, K and B fixed. A change in the conflict sign is not required for a composition effect: continuous Γ_seed, focal β and F/P/S viable seed responses are all retained, including null cells.
