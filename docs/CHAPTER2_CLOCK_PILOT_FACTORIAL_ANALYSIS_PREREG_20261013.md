## 1. What has been fixed and what is not known

The original 2,304-path retrospective cohort has one unchanged A heterozygote width and zero initial expected A Price response. Its t0 full-parent I Price response improves simpler models but not the strongest ecological/nonlinear I-genetics alternative at central L2. The prior on-path audit also found 299 A-first histories despite an earlier I-decline expected selection response. Neither result establishes a genetic-access→threshold-arrival clock. The next 1,536-path pilot therefore crosses previously registered **A halfwidth** (`L=0.046875`, `H=0.078125`) with **hidden within-individual I homolog variation** (`h=0` or `1`), preserving each original plant's expressed M/I/A phenotype and original immediate reproductive ecology.

All 1,536 original-source input identities were registered before generation: **2 genotype founder blocks × 3 fixed visitor regimes (0/3/4) × 2 A-access widths × 2 I-homolog states × 64 new paired stochastic histories/founder**. These are **128 founder×replicate stochastic clusters**, each with all 12 nested environments and genetic arms, not 1,536 independent islands. Unobserved trait-event thresholds and extinct populations stay in all denominators. The source response remains **founder-relative A increase/I decrease by 0.05 sustained 20 censuses**, with first-passage tie within five updates. Latest possible start is t=181 of 201 annual census records. Thresholds .025/.1, although stored by the original biological producer, are **outside the primary exploratory 0.05 table** and cannot be selected retrospectively.

## 2. Pre-outcome output and contrasts

No outcome will be analysed unless **all six source ZIPs**, **six separately physically supplied mirrors**, **six independently replayed native original-model readouts** and the final source review are complete. All six original reader receipts must match the external native-review receipt's exact SHA256s, which in turn binds the full 1,536-case aggregator. See [source gate](CHAPTER2_CLOCK_EXTERNAL_RAW_REDOWNLOAD_CONTRACT_20261013.md). The program never imports the biological producer, starts an evolutionary simulation, checks a live website or copies mock source data into an admitted scientific result.

Produce exactly **24 founder×ecology×A×I cells**, 64 original starts per cell. For each cell report the six mutually exclusive event counts/proportions, `p_A` (A onset observed), `p_I` (I-decline onset observed) and all-start `D=P(A-first)−P(I-first)` (simultaneous, single-trait and neither contribute 0 to this contrast; they remain counted in the six classes). These are occurrence/order summaries, not predicted 200-step response clocks, not individual causal mediation and not ecological root-finding.

Five **predeclared exploratory matched-treatment contrasts** are computed per founder×ecology, using each founder×seed cluster as an intact 2×2 block:

1. `Awidth_to_A_incidence`: high-minus-low A-event indicator averaged over both hidden-I arms.
2. `Ihidden_to_I_incidence`: I-homolog-present-minus-collapsed I-event indicator averaged over both A widths.
3. `Awidth_to_D`: high-minus-low difference in the 0.05 original six-class order score, averaged over I arms.
4. `Ihidden_to_D`: presence-minus-collapse difference in order score, averaged over A widths.
5. `Awidth_x_Ihidden_to_D`: conventional factorial interaction `D(H,1)-D(H,0)-D(L,1)+D(L,0)`.

Within each original founder×ecology cell (`64` founder-specific paired streams), report mean, empirical across-stream SD and descriptive SE for each contrast. Also average each contrast over **the three prespecified ecological contexts within each `(founder, replicate)`** and then report its overall mean and empirical SD/SE across exactly **128 full paired stochastic stream clusters**. No ecological units are invented. No p-value, nominal 95% confidence interval or post-outcome-selected threshold is reported from this exploratory pilot.

The word *intervention* refers only to a controlled **simulation genotype initialization**, not independent natural-island evolutionary histories. `h=0` collapses **within-adult homolog differences**, but retains between-adult expressed I variance; do **not** label this a zero-standing-variance treatment or a literal additive genetic variance manipulation. A width changes both segregation potential and mutation-free structural threshold support; it is not a pure single-coefficient adjustment. If any matched arms differ in t0 floral phenotype/ecological payoff, original inputs/reader must fail rather than reinterpret the contrast.
