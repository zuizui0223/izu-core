# Island ecology hypothesis recovery

## Submission-level decision

The primary scientific logic is closed for submission. The remaining unresolved branches are empirical translation questions, not missing admission gates for the current paper.

The paper should be read as a sequence of ecological hypotheses rather than as a method-first state-separability study.

## H1 — universal post-establishment response

**Prediction.** If island-associated pollinator functional simplification imposes a common post-establishment trajectory, established plant lineages exposed to the same functional perturbation should respond in one common direction.

**Test.** Ask whether positive and negative lineage responses coexist within the same matched stochastic run under one frozen model architecture.

**Result.** Rejected. Mixed-sign branching occurred in 0.4167 of matched runs in both the original and independently seeded blocks.

**Meaning.** A common pollinator-functional perturbation does not imply a universal lineage trajectory. This result does not reject aggregate island syndromes, because those may also arise through colonization and persistence filters.

## H2 — state-dependent branching

**Prediction.** Pre-existing lineage functional position is a necessary tested source of within-environment response-sign branching.

**Test.** Freeze the four downstream modifiers OFF and remove the residual lineage factors one at a time. Then repeat the strongest boundary under a predeclared independent seed and stop rule.

**Result.** Supported inside the declared ABM. Mixed-sign branching was 0.4167 in the full residual model and 0 after initial functional-position heterogeneity was removed. Trait-adjustment heterogeneity OFF and assurance-ceiling heterogeneity OFF retained branching. The same boundary replicated independently.

**Meaning.** The synthetic branch generator is initial functional position, not downstream dependency, assurance responsiveness, local support, or partner effectiveness.

**Boundary.** The standardized functional coordinate is not empirically identified as corolla length, flower area, nectar guide, colour, or any other single named trait.

## H3 — context-dependent branch allocation

**Prediction.** Local interaction context changes which branch a lineage occupies and may buffer some declines without being universally protective.

**Test.** Compare matched local-support OFF and ON states while autonomous assurance is disabled.

**Result.** Supported as a bidirectional branch allocator. Removing local support changed 105/288 paired lineage response signs. In the independent network-context block, support produced 16/96 sign rescues and 85/96 magnitude rescues, but also 11/96 worsenings.

**Meaning.** Network context is a context-dependent branch allocator with buffering capacity, not a universal shield.

## H4 — autonomous-assurance buffering

**Prediction.** Autonomous reproductive assurance should reduce the reproductive consequences of service decline and might, under a strong version of the hypothesis, reverse the response sign.

**Test.** Compare assurance ON versus OFF under identical upstream service change, then repeat in an independent block and a broadened support envelope.

**Result.** Magnitude attenuation supported; robust sign rescue rejected. Of 216 independent declines, 207 were attenuated. No sign rescue occurred in 216 independent or 525 broadened eligible declines.

**Meaning.** Assurance mainly dampens propagation magnitude in the current model; it is not a robust sign-reversing buffer.

## H5 — cross-island recurrence of response architecture

**Prediction.** If the state-dependent architecture has ecological relevance beyond the focal system, independent island systems should repeatedly occupy branching, same-direction propagation, and buffering/alternative response states without system-specific retuning.

**Test.** Challenge a frozen response-state vocabulary with source-locked external systems drawn from a 54-unit global screen. Do not rerun the ABM for new systems, retune parameters, add mechanisms, or relabel states after external inspection.

**Result.** Supported at the qualitative response-state level. Thirteen strict systems comprise three branching systems, six same-direction systems, two buffering/alternative systems, one reproductive-axis-decoupling constraint, and one retained falsification. All 11 generative challenges are covered or sign-compatible with response classes already present in the frozen model.

**Meaning.** The diversity of island responses is recurrent across independent ecological systems. This does not identify one shared empirical mechanism across all systems.

## Protected negative results

Four negative outcomes are part of the paper's logic and must remain visible.

1. **Dominica Heliconia:** the frozen signed-position projection failed in its declared direction and is not retuned.
2. **Puerto Rico–Mona Guaiacum:** visitor and reproductive axes decouple, so the system is not forced into a whole-reproduction buffering label.
3. **Network context:** 11/96 matched declines worsened, rejecting universal protection.
4. **Assurance:** robust sign rescue failed to replicate, so the stable claim is attenuation rather than sign reversal.

## Unresolved branches that remain scientifically valuable

### U1 — What is the real signed functional starting position?

This is the highest-value future test. The model identifies a synthetic relative starting position, but the empirical trait axis is unresolved. A direct test requires a source-native plant matching trait, a source-native pollinator functional center, and a signed mapping frozen before downstream response is inspected.

The preferred Izu route remains blocked because the needed pollinator functional trait values and plant-specific quantitative partner weighting are not currently source-complete. This does not block the present paper.

### U2 — Does real network context causally reallocate branches?

The synthetic route is strong, but strict empirical rate-weighted effective-service mapping is still incomplete. Retrospective systems provide partial bridges, not a complete admission of the local-support mechanism in a named real island transition.

This is a future empirical mechanism test, not a reason to weaken the current synthetic result or delay submission.

### U3 — Can one external system close the entire causal bridge?

The desired chain is:

`pollinator functional change -> effective service -> reproductive dependency/assurance -> downstream floral or reproductive response`

Several external systems provide adjacent links, but no current system closes the entire chain on compatible matched units. The completed external-bridge search therefore remains a partial-evidence result rather than an invitation to continue unconstrained literature search.

### U4 — Starting-state morphology recurrence

Two independent morphology analyses completed before the v12 branch-generator result show below-isometry OLS response directions consistent with starting-state dependence. Their measurement-error and EIV boundaries prevent promotion to a formal pooled coefficient or direct pollinator-matching validation.

Keep this as supporting context or Supplementary material.

### U5 — Colonization filtering versus post-establishment response

The present paper addresses the post-establishment response problem. It does not estimate how much of an aggregate island syndrome is generated by colonization, establishment, or persistence filtering. That decomposition requires a new hierarchical study.

### U6 — Universal cross-system effect size

Do not force a cross-island meta-analytic coefficient from noncommensurate visitation, pollen, morphology, seed-set, fruit-set, and network estimands. The current external series is a state-level challenge set, not a prevalence sample or a common-effect meta-analysis.

## What belongs in the main paper

The main text should contain H1–H5 and the four protected negative results. The ecological sequence is:

`common island-like perturbation`

`-> initial functional state generates branch potential`

`-> local interaction context reallocates propagation`

`-> assurance attenuates downstream magnitude`

`-> independent island systems repeatedly occupy the resulting response-state classes`

State separability remains useful only as an inference guard: same-direction response does not prove uniform starting states, and attenuation does not uniquely identify assurance.

## What belongs after the current paper

The next empirical programme should prioritize, in order:

1. a direct outcome-blind signed functional-position test;
2. a matched empirical network-context/effective-service test;
3. one complete external effective-service–dependency–response bridge.

None is required to submit the current island-ecology paper.
