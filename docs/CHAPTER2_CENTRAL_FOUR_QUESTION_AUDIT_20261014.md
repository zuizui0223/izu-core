## 中心質問

**送粉制限で繁殖上の見返りが変わったとき、繁殖保証と花への投資は、どの条件で、どの順序で、有限集団内の遺伝的変化として実現し、その違いは集団の存続にいつ結びつくのか。**

「条件 → 順序 → 実現 → 帰結」は研究を整理する4段階であり、因果鎖全体が実証済みという意味ではない。現在もっとも強く答えられる部分は、**繁殖保証の進化がなくても低い訪花者補充下で投資は低下し、保証を進化させると環境間の投資差が縮む**というModel 3内の結果である。4つの繁殖設定で前向き確認されているが、自然の島での歴史的経路や普遍法則の確認ではない。

「保証が先に進化すること自体が、その後の存続を改善する」は依然として未確立。論文の中心結論をこの強い因果主張へ置き換えない。

## Q2の説明で修正すべき2点

### 48.48%は普遍的な予測限界ではない

同じ初期遺伝子型と生態条件の18群について、各群の結果を見た後に最多分類を選んでも正答は1,117/2,304 = 48.48%。これは**この実現標本を、初期状態18群だけで決定的に分類するときの標本内上限**である。

「自然の進化順序の半分以上が原理的に予測不能」「母集団での正答率の上限48.48%」とは言えない。確率的な実現差を示すが、別標本、追加の許容される初期情報、確率予測の校正まで否定する結果ではない。6分類のうち厳密なA/I順序を達成した770例だけの値を全開始集団の性能へ置き換えない。

### 期待応答モデルはすべての対照より最良ではない

同じ履歴と生態条件をともに訓練から除いた探索比較で、中央のL2=0.15では：

| 初期情報 | 6分類の対数損失（小さいほど良い） |
|---|---:|
| 生態＋投資の遺伝的分散 | 1.47931 |
| 上記＋生態の二次項1つ | 1.44390 |
| 生態＋投資分散＋完全な親寄与からの投資期待応答 | 1.42169 |
| より柔軟な生態曲率・遺伝分散×供給の対照 | **1.41659** |

期待応答は同程度の複雑さの二次項対照より0.02221改善するが、柔軟な対照には対数損失で0.00510劣る。Brierは期待応答側がわずかに良く、評価尺度でも順位が異なる。両モデルとも既知結果に基づく探索比較であり、**「選択の期待応答には簡潔な予測に役立つ情報があるが、独自の優越性や二形質の時計は未確認」**が対応する結論である。
