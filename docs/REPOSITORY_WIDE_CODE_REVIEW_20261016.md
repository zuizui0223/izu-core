## 3. Scientific logic and circularity recheck

1. **Correct time direction:** Exogenous visitor state `V_t` and existing diploid plant state `G_t` → functional matching/pollen transport → female, male and viable selfed reproductive contributions → finite sampling/recombination/mutation → `G_{t+1}`. A recurrence through generations is expected; an endogenous plant→visitor population collapse loop is **not present**.
2. **Fitness definitions:** `W_i = F_i/2 + P_i/2 + S_i` is parental expected genetic contribution; `F+S` maternal viable output and 80-period occupancy are distinct endpoints. `W` is not equivalent to next-population occupancy.
3. **Q1 claims:** Original single-founder 4/4 positive A-evolvability divergence-compression remains valid under its settings. **Different 8×8 new-founder and visitor cohort:** three settings pass, direct assurance cost +0.044271 with 95% crossed interval [−0.044065,0.130837] is inconclusive; far-side relative investment preservation changes sign in two settings. No unique mechanistic attribution to initial genes versus new visitor trajectories.
4. **Q3 deterministic closure:** Density is a discrete nonlinear genotype map, **not a PDE, not the finite-ABM stochastic expectation**; it omits individual pollen self-exclusion and uses deterministic density regulation. Pure genetic-drift percentage cannot be estimated from their raw difference. Heat-PDE concerns the allelic mutation approximation only; ODE is reduced; full continuous-time SDE/SPDE remains unvalidated.
5. **Q4 occupancy:** The prehistory-A mode is also active through 80 future updates, and changing K in the canonical kernel changes both vacancy and the pollen background denominator. Thus a +10.84 percentage-point interaction is conditional on a **compound intervention**, not an identified allele-only history effect or natural order-mediated rescue.
6. **Separate cohorts:** Q1–Q4 compare different founders, visitors, genetic access, follow-up horizons and estimands. The four chapters of the story should be linked conceptually, **not** via an unmeasured numerical mediation pathway or a survival causal cycle.

## 4. Remaining risk register / do not overclaim

- **P1 science generality:** the direct assurance-cost setting is uncertain in the new independent founder×visitor cohort. Do not change original n=8×8 post hoc or pool unlike cohort bootstraps. The two regimes remain pollen-limited and synthetic.
- **P2 frozen producer safety:** Several archived legacy/active frozen reproduction runners use `assert` to guard critical receipt fields; Python optimized `-O` execution would suppress `assert`. The original producer SHA must remain immutable; any future rerun should use explicit error guards in a separately versioned runner rather than silently patching source history.
- **P2 original Q4 raw admission:** Execute strict readout on the original eight Q4 raw JSON shards with pinned source hash before claiming that newly hardened Q4 validation has been applied to all 4,096 actual futures. This is separate from the existing original biological replay and result receipts.
- **P2 provenance durability:** Q1 32 shard archive artifacts have 30-day GitHub Actions retention; the user-requested ZIP backup with all 33 original artifacts was independently saved in a previous session. A **public DOI dataset** remains blocked under [issue #436](https://github.com/zuizui0223/izu-core/issues/436). The repository isn't a DOI deposition service.
- **Coverage boundary:** 1,079 syntax scans and AST-risk flags ≠ 1,079 peer-reviewed numerical algorithms. In particular, numerous independently frozen old scripts and experimental tensor solvers have not each been source-by-source or high-resolution limit verified. The historical high-grid full three-locus mutation/PDE numerical gate remains stopped and non-admitted.
- **Testing direction:** Already verified Q1 full original raw re-admission plus model biological reproduction checks remain the basis for preserving present scientific conclusions. Any new producer version, genuinely new founder biology or exact Q4 re-analysis needs its own source pins and immutable archival receipt.
