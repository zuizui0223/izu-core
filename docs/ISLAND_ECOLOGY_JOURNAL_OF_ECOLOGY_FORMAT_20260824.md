# Journal of Ecology initial-submission format contract

Checked: 2026-08-24

This contract is editorial only. It must not trigger new simulations, external-system admission or field-data collection.

## Research Article target

Current first target: **Journal of Ecology**.

The journal accepts practical or theoretical ecological research and requires plant ecology to be central. Initial Research Articles are typically around 8000 words, with longer articles considered when justified.

## Initial-submission requirements to enforce

### Main manuscript

- English.
- Single column.
- Double line spaced in the submitted document.
- Continuous line and page numbering in the submitted document.
- Title.
- Abstract no more than **350 words**.
- Abstract in simple, factual, **numbered statements**.
- Final abstract point headed **Synthesis** and stating the general ecological advance in non-specialist terms.
- Main sections:
  1. Introduction
  2. Materials and Methods
  3. Results
  4. Discussion
  5. Conclusions optional
  6. References
- Figures and tables may be embedded in the main file for review.
- In-text citations should use `(Author, Year)` style where practical; exact reference formatting is not required at initial submission.
- Code/data must be available for peer review either as uploaded review files or through a suitable private peer-review repository, and this availability must be stated in the manuscript.

### Double-anonymous review boundary

Keep reviewer-facing files free of obvious author identity.

- title page is separate from the anonymous manuscript;
- no author names, affiliations, personal email addresses or identifying acknowledgements in reviewer-facing files;
- do not use first-person ownership such as “our previous study” where it reveals identity;
- public GitHub username / identifying repository link should not appear in the anonymous review manuscript if it identifies the authors;
- cover letter and title page may contain author identity.

## Proposed numbered abstract structure

1. **Background/question:** recurrent island reproductive syndromes coexist with heterogeneous post-establishment responses to pollinator-functional change.
2. **Approach:** frozen ABM, factorial/residual ablations, independent branch-generator replication, strict external challenge from 54 screened units / 13 systems.
3. **Main results:** initial functional position collapses branching when removed; network context reallocates/rescues/worsens; assurance attenuates magnitude without robust sign rescue.
4. **External challenge:** three branching, six propagation, two buffering/alternative, one axis-decoupling constraint, one retained falsification; 11/11 generative challenges state-covered/sign-compatible.
5. **Synthesis:** aggregate island syndromes can coexist with lineage-level branching because colonization/persistence shape which states arrive while starting state and local context shape how established lineages respond.

## Journal-fit stop rule

Formatting is not a scientific reopening trigger. If a journal requirement cannot be met without adding analyses, the manuscript should be repositioned or the limitation stated; do not alter the frozen model merely to improve journal fit.
