### R2 — pilot feasibility/dispersion

Collect or identify only the pilot information needed to replace planning assumptions:

Pilot data are for design calibration. They do not authorize predictor selection by favorable effect direction.

## Scientific payoff of doing the pre-data work now

If the later field result is positive, the claim is strong because the mapping and analysis existed first.

If the later result is null/adverse, the result is still publishable and theoretically informative because it falsifies or limits transport of a previously frozen mechanism.

If the measurement gate fails, the result is `NOT_EVALUABLE`, which identifies the measurement bottleneck rather than converting missingness into biological absence.

That is the intended value of the pre-data phase.
