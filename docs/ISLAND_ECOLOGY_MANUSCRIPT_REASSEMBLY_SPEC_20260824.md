# Island ecology manuscript reassembly specification

## Purpose

This file fixes the primary manuscript order after restoring island ecology as the scientific mainline. It changes framing and section order only. It does not reopen simulations, external-system admission, parameter selection, state classification, or empirical field requirements.

## Preferred title

**One perturbation, multiple island responses: state-dependent branching under pollinator functional simplification**

## Core manuscript question

**Why does island-associated simplification or reorganization of pollinator function produce divergent plant responses rather than one universal post-establishment trajectory?**

## Introduction order

### Paragraph 1 — island syndromes and the two-layer problem

Start from recurrent island-associated reproductive patterns, then distinguish:

- colonization / establishment / persistence filtering; and
- post-establishment response of lineages already present when pollinator function changes.

Do not frame the paper as a rejection of island syndromes.

### Paragraph 2 — empirical heterogeneity after establishment

Establish that pollinator loss, partner replacement, invasion, network reorganization and disturbance can propagate differently across plants. The biological problem is therefore not simply whether island reproduction declines, but why similar functional perturbations produce different downstream states.

### Paragraph 3 — state-dependent ecological hypothesis

Introduce the causal ordering:

`common pollinator functional change`

`x pre-existing lineage functional state`

`-> branch potential`

`-> local interaction context reallocates propagation`

`-> reproductive assurance modifies downstream magnitude`

### Paragraph 4 — why a frozen ABM is needed

Use the ABM as the experimental device that permits controlled removal of candidate mechanism families. Equifinality and state separability are methodological safeguards, not the primary scientific question.

### Introduction-end hypotheses

State H1–H5 explicitly:

- **H1 universal-response hypothesis:** a common perturbation produces one common downstream direction. Prediction is rejected if mixed signs coexist within a matched environment.
- **H2 state-dependent branching hypothesis:** removing pre-existing functional-position heterogeneity eliminates within-environment branching while other single residual removals do not.
- **H3 context-dependent propagation hypothesis:** local interaction context reallocates branch identity and may rescue or worsen declines.
- **H4 assurance-buffering hypothesis:** assurance reduces downstream reproductive impact; strong sign reversal is a stronger subprediction and may fail independently of attenuation.
- **H5 cross-island recurrence hypothesis:** branching, propagation and buffering/alternative states recur in external island systems without system-specific model retuning.

Do not end the Introduction with sensitivity/specificity as the main question.

## Results order

### 3.1 H1 — one architecture produces more than one island response

Lead with the ecological contradiction to a universal post-establishment trajectory: full runs contain both branching and same-direction outcomes.

### 3.2 H2 — pre-existing functional position is the replicated minimal branch generator

Present original and independent ablation blocks together. This is the main mechanistic result.

### 3.3 H3/H4 — downstream context reallocates branches; assurance attenuates magnitude

Keep local-support paired sign changes, network rescue/worsening and assurance attenuation/sign-rescue failure in one ecological mechanism section.

### 3.4 H5 — external island systems reproduce the response-state diversity

Present the 13 strict systems as:

- 3 branching;
- 6 same-direction propagation;
- 2 buffering/alternative;
- 1 axis-decoupling constraint;
- 1 retained falsification.

Explicitly state that the set is a strict state-challenge set, not a prevalence sample and not 13 independent tests of one causal mechanism.

### State-separability placement

Move the detailed sensitivity/FPR/specificity table out of the central Results sequence. Main text may retain one short inference-boundary paragraph after the ecological results. Full diagnostics belong in Supplementary material or a supporting methods/result box.

## Discussion order

### 4.1 Aggregate island syndromes can coexist with lineage-level branching

Primary synthesis:

**An aggregate island syndrome does not imply a universal within-lineage post-establishment trajectory.**

Explain how colonization/persistence filtering can create macroecological regularities while established lineages still respond conditionally to changed pollinator function.

### 4.2 Functional starting state determines branch potential

Interpret H2 biologically. Emphasize relative position in plant–pollinator functional space rather than a named floral trait. Keep the empirical identity of this axis unresolved.

### 4.3 Local interaction context governs propagation; assurance mainly dampens it

Discuss network context as a bidirectional allocator rather than universal resilience. Contrast strong sign rescue with weak magnitude attenuation. This replaces the current method-first heading `The inverse problem is the main methodological result`.

### 4.4 Cross-island recurrence supports a response architecture, not a universal mechanism

Use the 13-system comparison to establish recurrence of response classes. Preserve Guaiacum and Dominica as constraints against over-generalization.

### 4.5 What remains unresolved empirically

Keep three future tests only:

1. outcome-blind signed functional starting position;
2. matched real network-context/effective-service mechanism;
3. a complete external service–dependency–response bridge.

Do not reopen a generic search for more island examples.

### 4.6 Inference boundary

State separability can be summarized here or in Supplementary material:

- branching is informative when present but not required whenever starting-state heterogeneity exists;
- same-direction response is not evidence of homogeneous lineages;
- attenuation alone does not identify assurance;
- state compatibility does not identify a real-world mechanism.

This is a guard on the ecological interpretation, not the paper's main novelty.

## Material that must not return to the mainline

- method-first MEE framing;
- `inverse problem` as the main result heading;
- sensitivity/specificity as the primary Abstract conclusion;
- universal island-syndrome rejection;
- one empirical mechanism assigned across all 13 strict systems;
- cross-system prevalence estimates from the 13-system challenge set;
- a pooled common effect across noncommensurate response axes;
- new simulation runs for narrative cleanliness;
- additional seed search;
- field data as a prerequisite for submission;
- retuning Dominica or relabelling Guaiacum.

## Editorial completion criterion

The manuscript is ready for journal-specific formatting when the Introduction, Results, Discussion and figure captions all preserve the same causal ordering:

**starting state -> branch generation -> context-dependent propagation -> assurance attenuation -> cross-island recurrence -> empirical mechanism boundary.**
