# Current comparative island evidence state

Updated: 2026-08-22

This is the top-level state for the island comparative programme. `docs/CURRENT_EVIDENCE_STATE.md` is retained as the **Izu/Campanula calibration substate** and must not be read as the programme-wide scope.

## Decision

The inferential unit is the **independent island system**, not Izu alone. Multiple biological systems from one archipelago can inform different mechanism links, but they do not automatically create additional independent geographic replicates.

Current programme question:

> Across independent island systems, which upstream pollinator-functional changes recur, which downstream response branches follow, and what determines whether those changes propagate into reproductive or floral evolutionary response?

## Current response / propagation vocabulary

- pollinator functional environment / matching;
- floral morphology;
- mating and reproductive assurance;
- visual signal, including nectar guides / UV signal;
- pollinator effectiveness and effective service;
- interaction-network structure / rewiring;
- reproductive outcome;
- propagation boundary: a demonstrable upstream change that does not force the same-sign downstream response.

Systems are not required to measure every axis. Missing is not zero. A blocked or buffered propagation step is itself an admissible biological result.

## Current system coverage

The committed system matrix contains ten broad routing entries assembled from the real-data scale registry and external bridge registry: Izu, Seychelles, Galápagos, Balearic, Canary, Hawaii, Dominica/Lesser Antilles, California Channel Islands *Nicotiana*, Caribbean Gesneriaceae, and Xisha *Cordia*.

The latter is a new mechanism system but **not** a new geographic stratum beyond Hawaii.

This routing count is not an inferential sample size. Panels, flowers, visits, plants, seasons, papers and biological systems nested within the same geography are not promoted mechanically to independent evolutionary replicates.

## Strongest current comparative result

A universal directional island syndrome is not supported. The recurring result is **response heterogeneity, alternative response combinations and incomplete propagation**.

The Hiraiwa cross-study triangulation is a direct example: the three shared taxa do not collapse onto a uniform matching↓ + tube↓ + pollen↓ cascade; the observed count is 0/3. At the wider eight-target Izu level, corrected matching is lower across all shared targets while pollen and tube responses branch in sign. This supports a common-ish upstream constraint coexisting with divergent downstream responses, not same-estimand replication, mediation, or historical Bombus causation.

Across the broader matrix, different systems contribute different combinations of morphology, reproductive assurance, effectiveness, network change and reproductive outcome. These axes must remain distinct unless compatible estimands justify formal synthesis.

## Hawaii 2026 propagation boundary

The 2026 Hawaiian lobelioid literature adds a high-value source-triggered bridge.

Case et al. (*Functional Ecology*, 2026) define a source-native signed position:

```text
bill_minus_flower = bird culmen length (mm) - plant flower length (mm)
```

Contemporary bird assemblages are reported to shift toward more negative positions across most islands after loss of long-billed nectarivores. The same study reports that pollen-contact probability rises and nectar-robbing probability falls as bill length approaches flower length.

A closely overlapping Case et al. (*Ecology and Evolution*, 2026) field/experiment system on *Cyanea shipmanii*, *Clermontia pyrularia* and *C. lindseyana* reports fertile-structure contact in 43% of visits and nectar robbing in 39%. Experimental robbing damage altered nectar replenishment, yet fruit production and seed viability remained high across treatments.

The mechanistic lesson is not that mismatch is harmless. It is that:

```text
functional position / mismatch
        -> interaction quality can change
        -> resource dynamics can change
        -X-> reproductive collapse is not automatic
```

This supports a real **propagation boundary**: interaction-quality change can be absorbed or buffered before the final reproductive endpoint.

The two papers are not treated as one tagged-individual causal chain, and their exact raw interaction rows are not linked in izu-core because the Functional Ecology CSV remains inaccessible. The raw source gate is frozen as an access block: direct Dryad streams returned 403 and the official dataset-package API returned 401 without bearer authentication. No raw values are reconstructed from the paper.

## Nectar-guide / visual-signal status

That Izu-specific missingness does **not** remove nectar guides from the programme.
