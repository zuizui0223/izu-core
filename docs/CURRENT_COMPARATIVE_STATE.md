# Current comparative island evidence state

Updated: 2026-08-18

This is the top-level state for the island comparative programme. `docs/CURRENT_EVIDENCE_STATE.md` is retained as the **Izu/Campanula calibration substate** and must not be read as the programme-wide scope.

## Decision

The inferential unit is the **independent island system**, not Izu alone.

Current programme question:

> Across independent island systems, which plant response axes change under altered pollinator functional environments, which combinations recur, and what explains recurrent heterogeneity?

## Current response-axis vocabulary

- floral morphology;
- mating and reproductive assurance;
- visual signal, including nectar guides / UV signal;
- pollinator effectiveness and effective service;
- interaction-network structure / rewiring;
- reproductive outcome.

Systems are not required to measure every axis. Missing is not zero.

## Current system coverage

The committed system matrix currently contains ten system-level entries assembled from the real-data scale registry and external bridge registry: Izu, Seychelles, Galápagos, Balearic, Canary, Hawaii, Dominica/Lesser Antilles, California Channel Islands *Nicotiana*, Caribbean Gesneriaceae, and Xisha *Cordia*.

This count is a routing inventory, not an inferential sample size. Panels, flowers, visits, plants and seasons nested within systems are not promoted to independent evolutionary replicates.

## Strongest current comparative result

A universal directional island syndrome is not supported. The recurring result is currently **response heterogeneity and alternative response combinations**.

The Hiraiwa cross-study triangulation is a direct example: the three shared taxa do not collapse onto a uniform matching↓ + tube↓ + pollen↓ cascade; the observed count is 0/3. This supports recurrence of heterogeneous response modes, not same-estimand replication, mediation, or historical Bombus causation.

Across the broader matrix, different systems contribute different combinations of morphology, reproductive assurance, effectiveness, network change and reproductive outcome. These axes must remain distinct unless compatible estimands justify formal synthesis.

## Nectar-guide / visual-signal status

Visual signal is an **active comparative response axis**.

The Izu calibration contract currently lacks an adopted quantitative nectar-guide / visible-signal measurement, so Izu contributes a `missing_current_measurement_not_zero` cell on this axis. That Izu-specific missingness does **not** remove nectar guides from the programme. Any system-specific nectar-guide, visible or UV signal measurement can enter the comparative matrix when its source, measurement definition and sampling unit are locked.
