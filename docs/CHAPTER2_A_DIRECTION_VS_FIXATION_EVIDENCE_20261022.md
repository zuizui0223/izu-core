# Aの終点収束を「方向性のある繁殖」と「アレル固定」に分ける（保存結果のみ、2026-10-22）

**結論：方向性のある繁殖上の利益と、中立的な頻度変化・固定による終点集中は区別できる。しかし反復性の何％が選択、何％が固定かを互いに独立の因果寄与として割り振ることはできない。** 固定は選択の帰結でもあり、両者は排他的な機構ではない。新しい生物学的シミュレーション・検定・確認実験は実施していない。

再計算コード：[`scripts/summarize_chapter2_A_direction_fixation_existing_20261022.py`](../scripts/summarize_chapter2_A_direction_fixation_existing_20261022.py)。既存の六つの数値ソースだけを読み、四種類の**別コホート**の結果を数値監査する。異なる実験の効果量・独立単位はプールしない。

## 1. 160×160確証実験のA遺伝子型：固定「の有無」と固定「の向き」は違う

事前登録された高I支持範囲G／資源条件別存続Sの検定と**別の、事後的なA終点記述**。資源予算B8は両政策とも25,600/25,600集団が世代80まで生存。160の創始者と160の送粉履歴を交差した単位であり、25,600の独立島ではない。Aを発現固定にしても潜在的Aアレル（0.25, 0.50, 0.75）は遺伝する。両政策は各創始者内で初期A発現0.5かつ同一初期遺伝子型に揃えている。

| B8、80世代目（全開始集団を分母） | A発現固定 | A進化可能 |
|---|---:|---:|
| A遺伝的固定、いずれかの値 | 15,664/25,600 = 61.1875% | 25,582/25,600 = 99.9297% |
| 0.25に固定 | 5,332 | 0 |
| 0.50に固定 | 5,187 | 275 |
| **0.75に固定** | **5,145/25,600 = 20.0977%** | **25,307/25,600 = 98.8555%** |
| 生存しA多型が残る | 9,936 | 18 |
| 固定した集団のみでの固定世代中央値 | 55 | 36 |
| 生存・多型の平均持続世代数 | 64.4575 | 34.8041 |

A=0.75への固定率の**政策差は +78.7578125ポイント**（事後的記述値；新たな信頼区間なし）。「発現を固定するとAの遺伝的固定は起こらない」は誤り。発現を固定した政策でも約61%はどれかのアレルに固定するが、その値は低・中・高に分散する。一方、発現を進化可能にした政策では高Aに著しく偏る。したがって**ランダムな固定だけで一方向の高A集中を説明することは難しい**。

ただしA固定発現群は完全な中立ゲノムではない。I/Mとの遺伝的関連や家系寄与、A発現による個体数・繁殖様式の変化も政策差に含まれ、+78.76ポイントは「自然選択だけの独立寄与率」ではない。

原資料：[160×160確証](CHAPTER2_CONFIRM160_RESULTS_20261019.md)、[世代別固定・多型の読み取り](CHAPTER2_VARIATION_CLOCK_RESULTS_20261019.md)。

## 2. 旧K32の中立対照：方向性は固定境界だけでは生まれない

別の既存研究：K32、突然変異なし、8世代、**送粉履歴は一つだけ**、512の入れ子の人口学的反復。事前登録160×160の一般化検定ではない。

同じ実現個体数を条件にした、中立なメンデル遺伝・親の均等な寄与を使う対照の比較：

| 終点の高Aアレル頻度 | 元Model3 | 中立対照 |
|---|---:|---:|
| B8 | 0.977264 | 0.501190 |

対応する元モデル−中立の差は **+0.476074**（既報の入れ子反復Monte Carlo区間0.460023–0.492126）。中立モデルでは、p=0.5からランダムに固定することはあっても、平均を系統的に0.98まで引き上げることはできない。この**元モデル特有の非中立な繁殖方向**は既存データで支持される。ただし中立対照は繁殖生物学を変更する人工比較で、源モデル内の遺伝・花粉媒介・交配寄与をさらに純粋な選択係数へ分解していない。

別の旧K32計算では、アレル頻度変化
\[
p_{t+1}-p_t=(q_t-p_t)+(p_{t+1}-q_t)
\]
を各生存経路で厳密に再現した。B8のA高アレルの8世代累積平均：条件付き繁殖方向 **+0.480941**、有限子孫サンプリング残差 **−0.003372**、実測 **+0.477570**。方向項と有限実現項は統計的に関連し得るため、これを二つの独立した分散寄与率として加算してはいけない。

参照：[元モデルと中立対照](MODEL3_K32_NEUTRAL_MATCHED_CENSUS_BOUNDARY_20261009.md)、[経路ごとの厳密分解](MODEL3_K32_PATHWISE_DIRECTION_AND_SAMPLING_20261009.md)。

## 3. 旧K32の平均軌跡・個体数一致対照：終点集中は元モデル固有の安定化選択を要しない

さらに**別に実施された**旧K32の事後的な人工比較では、各世代の平均高A頻度と実現個体数を元モデルに合わせた。B8では

| | 元モデル | 人工比較 |
|---|---:|---:|
| 高A終点平均 | 0.978271 | 0.977997 |
| 終点頻度分散 | 0.001888 | 0.000895 |
| 高A完全固定率 | 62.3% | 48.2% |

比較モデルも頻度上限1に向かい、元モデルより**小さい**終点分散を生じた。このモデルは遡及的に平均を合わせる追加の方向バイアスを持つため、「上限だけで説明できた」わけでも「元モデルの安定化選択の寄与はゼロ」でもない。**上限・固定と、方向性を持った継承を組み合わせるだけでも反復性の指標が現れる**ことが分かった、というのが妥当。

## 4. 個体あたり繁殖利得の解析的検査：後期の無送粉条件

160×160の生殖モデルは、35世代以降は機能的訪花者ゼロ、遅延型の自殖保証で、資源B8、保証コスト0.5、近交弱勢0.5、花投資Iのコスト0.5、送粉割引0。

花投資Iを固定し訪花による他殖がゼロなら、期待する生存自殖種子数は

\[
W(A\mid I)=8\,\mathrm e^{-0.5I^2-0.5A^2}\,(1-0.5)A,
\qquad
\frac{\mathrm d\log W}{\mathrm dA}=\frac1A-A>0
\quad(0<A<1).
\]

I=0.5ではA=0.25、0.5、0.75の順に **0.85535、1.55760、1.99843** 生存自殖種子数となる。A=0.75の個体はA=0.5の個体よりこの条件付き期待量で約28.3%高い。**直接的な母性繁殖利益の向きは解析的に示せる。** ただしこれは遺伝的背景とIを固定した局所比較であり、3遺伝子座を通じて実際に観察される個体群の選択係数や「全固定の原因割合」を特定するものではない。

## 論文で採用できる表現と、残る識別限界

**使える：**「Aは繁殖上の条件付き正の方向性を持ち、実際の高Aへの集中は中立な固定だけでは説明されない。一方、終点の高い反復性には、方向的変化によって到達したアレル上限・固定も寄与し、これを元モデル固有の安定化選択と同一視できない。」

**使わない：**「Aの反復性のX%は選択、残りY%は遺伝的浮動」、「固定とは無関係にAは決まる」、「選択は必ず高Aへ固定させる」、「花投資の97.6%は偶然」、「160×160とK32は独立に同一推定量を確証した」。

もし特に**低い終点分散を生む選択特有の負フィードバックの寄与率**を主張したいなら、初期遺伝変異・人口過程・時間ごとの方向バイアス・吸収境界を系統的に対応させた**新しい介入モデル**を事前に設計しなければならない。既存ソースのみではその割合は一意に識別できない。これは新規生物学実験なしで現時点で確定できる識別範囲である。

現行論文 R3 には、反復性を「選択か固定かの二者択一」にせず、**方向的繁殖利得 → アレル頻度上昇 → 固定境界による終点集中**という機構候補として短く追加できる。登録済み R4 のG/S主要結果は独立のまま維持する。
