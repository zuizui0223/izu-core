# Model 3 島嶼生態学：完走結果の解釈（2026-09-27）

本報告は、凍結した80条件・19,968ケースの結果を扱う。128の独立履歴と通常2回の人口学的反復を使用し、検証用履歴群を含む集計は86行。全ケースの記録・状態保存則の監査と、事前指定80ケースの完全再現を通過した。元の12時間制限による停止は保存し、ホストのスタンバイを受けた明示的な追加計算枠で完走した。生物学的設定・履歴・閾値は変更していない。

**中心的な結果は、現在の送粉環境だけでは、過去に送粉者を失った有限個体群の花への投資を予測しきれないことである。** ただし、これは本モデルとその離散化に条件づけられた結果であり、連続形質極限への数値収束は未確立である。既存Q1は着想であり、4地域への当てはめも再現も行っていない。

## 1. 花への投資低下は、自殖だけか、誘引利益の変化か

固定状態の繁殖実験は、遺伝子頻度を変えずに個体の投資表現型を微小変化させ、母・父双方の他殖寄与を半分ずつ計上し、生存可能な自殖子の寄与を足した期待繁殖寄与の勾配を測る。実現した次世代の選択差や個体群成長率そのものではない。

送粉活動0.05、マッチした送粉者、コスト係数0.5の場合、自殖能力0では総寄与勾配は+0.570（95%履歴ブートストラップ区間0.552–0.587）。同じ条件で自殖能力0.5では−0.416（−0.430–−0.402）。コストを0にすると後者も+0.584となる。活動0.4、マッチした送粉者では自殖能力0.5・コスト0.5でも+1.530だが、機能的ミスマッチでは−0.624になる。

したがって、この実験範囲では「送粉者減少だけで必ず誘引形質が減る」とは言えない。送粉が乏しいと他殖による追加利益が小さくなり、自律的繁殖が可能な植物では、誘引投資を減らして繁殖資源を保つ方向が有利になり得る。コスト係数自体を送粉者減少で増やしてはいない。自殖と直接の投資利益は排他的な二択ではなく、相互に作用する。

自殖能力を固定しても花への投資が低下するため、自殖能力の進化は低下の必要条件ではない。一方、これは自然データ上の直接・間接効果を同定した媒介分析ではない。花色・花形の単純化を直接再現したものでもない。

## 2. 消失の時期とミスマッチ

200繁殖年の比較で、共通の最後120年を持つ早期消失・後期消失を比べた。終端投資の初期値からの変化は、無中断+0.2115、早期消失−0.1603、後期消失+0.0322。各条件256/256個体群が終端まで存続した。早期消失と無中断との差は−0.3718（−0.3948–−0.3499）。早期・後期ミスマッチではそれぞれ+0.0701、+0.0942で、完全な不在とは異なる応答となる。

同じ回復環境を経験しても、既に変わった遺伝子頻度・残存変異・個体群の履歴が、その後の応答を制約するという解釈に整合する。ただし、この比較だけで変異喪失を唯一の原因と同定してはいない。特定の島の絶滅年代や到着年代に校正した結果ではない。

## 3. 繁殖保証と存続

早期の送粉者不在下で、自殖能力を0に固定した一年生群では終端生存0/256。固定0.5、固定0.9、および自殖能力が遺伝する各条件では256/256が存続した。この強い差は、完全な送粉者不在・成体の年更新・種子による救済なしという設定に依存する。

遺伝する遅延自殖では投資変化−0.1781、先行自殖では−0.2143。保存された実現自殖割合の平均はそれぞれ約0.684と0.914。これは生存して加入した在来子のうち自殖子が占める割合であり、移入個体を分母に含まず、自殖能力の遺伝子値と同一ではない。近交弱勢は0.5で固定し、遺伝的負荷やパージングの進化は扱わない。

## 4. 距離は植物と送粉者で分ける必要がある

距離はkmではなくそれぞれの分散スケールで規格化した0・1・3である。種子距離0で、送粉者距離を0から3に増やすと投資変化は+0.0803から−0.1312に変わる。送粉者距離3では種子距離を0から3に増やすと−0.1312から−0.0757となり、同じ単調な「隔離が強いほど減少」という一本の軸にはならない。

種子移入は個体数と遺伝子流動、送粉者移入は繁殖環境を変える。この二つを一つの地理距離にまとめると異なる作用を混同する。ここでの履歴は到着・消失の群集形成を含むため、純粋な到着順序効果とは区別する。

## 5. 海洋島の創始と大陸島の分離

空の島からの成立条件では255/256が終端に存在した。初期植物が存在しないため、創始時点の花形質からの変化は定義しない。同じ初期植物・送粉者・将来履歴を与えた創始ラベルと分離ラベルの対照は同じ結果となった。

これは、海洋島と大陸島を名前だけで異なる結果にしていないことの確認である。実際の成立史の効果は、継承される植物・送粉者群集、創始集団、経過時間の差を通じて検証する必要がある。現実の地史を本計算で再現したとは言わない。

## 6. 送粉者が戻れば花も戻るか

送粉者だけの回復では投資変化−0.1603。供給源由来の種子追加では−0.0919、現在の居住個体と同じ遺伝子分布を持つ移入対照では−0.1597。各処置には対応する無中断対照があり、それとの差も全て保存されている。単なる個体追加と、供給源由来の遺伝的組成を持つ個体追加の作用を分ける設計である。

供給源種子の処置では終端の創始者由来遺伝子割合は約0.893、居住者型追加では約0.957。したがって、変化を全て元の居住系統の適応と呼べない。置換・混合を含む。

200年の変異率0.001処置では、終端投資ヘテロ接合度は0.0836となるが投資変化は−0.1612で、変異供給だけで無中断軌道に戻るわけではなかった。2,000年の条件では無変異−0.2571、変異率0.0001で−0.2522、対応する無中断はそれぞれ+0.2156、+0.2094。回復の不足が観察期間内で持続する結果であり、永久的不可逆性や平衡到達の証明ではない。長期条件の不在期間も長いため、200年結果との単純な時間延長比較はしない。

## 7. 有限個体群と分布モデル

固定の種子供給で容量48・192・768を比べると、個体モデルの投資変化は+0.2063、+0.2851、+0.3288。対応する分布モデルは約+0.3580、+0.3592、+0.3595。容量増加とともに平均の差は縮む。個体あたり移入率を固定した別系列でも同じ方向である。

ただし消失後には個体モデルが負、分布モデルが正となる条件がある。差は単なる一定倍率の減衰ではない。また有限個体の自己花粉除外、繁殖・生存・加入の標本化、非線形な容量制限、遺伝的変異の変化が含まれるため、全てを遺伝的浮動に帰属しない。既存の一段階の期待値・花粉除外監査は、その演算を検証する対照であり、長期差を加法的な寄与率に分けるものではない。比較相手は離散遺伝子型分布モデルでありPDEではない。

## 8. 生活史と時間尺度

400年の中断条件で、毎年の繁殖予算が同じなら、一年生・期待寿命4年・10年の投資変化は−0.2434、−0.0721、+0.0264。一方、生涯予算を合わせると4年・10年は−0.1469、−0.1483。長寿そのものだけでなく、一生の繁殖量とその配分が結果を変える。

記録された親年齢による平均世代間隔は約1.00、3.96、9.71年。したがって400年を全条件で400世代とは呼ばない。10年寿命・年予算固定では終端ヘテロ接合度0.1883、生涯予算固定では0.0347で、遺伝的保持も異なる。

旧モデルのkは独立履歴のプール数だった。本モデルの生存重みは一成体の時間的な経験であり、同一の量ではない。固定された送粉サービスの21植物参照パネルは保存しているが、中断系列は非定常、一定系列は分散0となる。群集形成系列も初期過程を含み、妥当な定常共分散とその不確実性を確認していない。よって実効kへの数値換算は現時点ではnot_evaluableとする。世代間隔や寿命をkと読み替えない。

## 9. S/C/Iと予測の持ち運び

Sは初期投資状態、Cは外生的な群集履歴、Iは両者の非加法成分。これはセル平均の記述的分解であり、2回の人口学的反復に由来する雑音を差し引いた潜在分散比ではない。例として訓練側の近距離はS=0.275、C=0.377、I=0.348、遠距離はS=0.191、C=0.527、I=0.282。検証側でもC>I>Sとなったが、順位の信頼区間や順位の普遍性は示していない。特に検証近距離ではIとSはほぼ同値である。

初期状態別平均の予測では、同じ距離条件の別履歴への平均絶対誤差は0.0150、0.0106。距離条件をまたぐと0.1581、0.1417に増える。成分の順位が同じでも、平均応答の予測が持ち運べるとは限らない。これは特定の宣言済み分布間の点推定であり、全島嶼への転用保証ではない。存続はこの部分の全ケースで一定なので、存続のS/C/Iは分散0で評価不能。

## 数値精度、一般化、新規性

16の格子比較で、個体モデルの差の95%区間が±0.01内に完全に入る対はなかった。7→11点で小さい平均差でも区間が許容幅を越える。連続更新条件でも初期個体は格子へ投影されるため、格子間差には初期状態の離散化も含む。詳細は数値評価表を参照する。条件付き平均の精度目標は70行中4行で達成、64行で未達、2行で定義不能。これは方向の区間が0を含むかとは別の判定である。

最も有望な着眼点は、繁殖保証・送粉履歴・遺伝的補充を分け、現状の送粉環境が同じでも残る花への投資の差を説明することである。自殖による救済、優先効果、有限個体群と決定論的記述の違い自体を新規発見とはしない。先行研究整理（MODEL3_NEAREST_PRECEDENTS_20260926.md）が指摘する近接研究との式・設定の比較は、優先権主張の前に必要である。本報告は世界初を認定しない。

現実の島への予測は、訪花数だけでなく機能的マッチ・花粉送達・自殖能力・実現自殖・加入・遺伝的変異・種子流入・世代間隔を同時に測る設計へ接続できる。送粉者回復前後に花だけでなく遺伝的組成を追うことで、元の系統の変化と移入による置換を分ける。未測定の42島やQ1の4地域に本結果のS/C/I値を割り当てない。
