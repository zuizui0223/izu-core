# Unified Model 3 projection onto existing real-island evidence — 2026-09-27

Status: exploratory reinterpretation of already source-locked Chapter 2 evidence. No new natural data are introduced and no model parameter is fitted to an island system.

## Decision

The old real-island confrontation becomes more useful under the unified Model 3 architecture if it is treated as a **layer-by-layer confrontation**, not as a parameter mapping exercise.

Natural systems are asked three different questions:

1. **A — ecological/selection layer:** do plant state, visitor functional composition, interaction quality or reproductive return show the state-dependent structure required for branching?
2. **B — deterministic inheritance layer:** is there a directly observed longitudinal inherited trait/genetic trajectory under a measured visitor regime?
3. **C — finite/history realization layer:** do disturbance chronology, reproductive assurance, immigration, founding, connectivity or demographic persistence change the realized outcome?

Model 3 parameters are not estimated from these systems. A system can support one layer and be uninformative at another.

## What the existing world evidence already says

The existing `island_system_propagation_matrix_v1.json` contains 14 source-locked biological system layers across 12 geographic clusters. Their descriptive propagation states are:

- same-direction propagation: 1;
- downstream branching: 2;
- buffered/resilient: 3;
- counterdirectional: 1;
- adjacent links only: 4;
- unresolved missing link: 3.

This distribution should not be interpreted as natural prevalence because the rows are heterogeneous and not independent sampling units. Its value is qualitative: the existing natural evidence already contains the same vocabulary needed by the unified Model 3 — propagation, branching, buffering, reversal and missing links — rather than one universal island trajectory.

## Historical / finite-realization anchors outside the 14-layer matrix

Three old world-confrontation systems are especially valuable for the C layer of Model 3:

### Surtsey — founding chronology

Surtsey provides a dated empty-start island, early establishment under low pollinator availability, and later reproductive-system/seed comparisons. It is a natural analogue of the Model 3 founding/history family, but not a full pollinator-transition test because the focal partner trajectory is not measured end-to-end.

### Tiritiri Matangi — recovery and compensation

Hihi reintroduction provides direct partner-arrival history, and later pollinator-exclusion work measures reproductive function. The important result is not simple restoration: other birds can compensate. This is a natural analogue of Model 3 recovery/buffering, where restoring one partner need not restore the previous trajectory one-for-one.

### New Zealand *Rhabdothamnus* and Mariana bird-loss systems — loss plus demographic/reproductive consequences

These are among the stronger old natural experiments because partner loss is directly observed and reproductive or recruitment outcomes are measured. They are therefore more informative for the finite/history realization layer than ordinary cross-sectional island-mainland comparisons, although source floral state and full matching/effectiveness chains remain incomplete.

## What real islands can and cannot currently test

### A — ecological/selection branch: partly testable now

The existing evidence is already informative. Izu, Ogasawara, Xisha, Hawaii and Seychelles show that functional matching, access and visitor effectiveness are plant-specific and that downstream response need not be uniform. This is the natural layer most directly aligned with the new fixed-state Model 3 result.

### B — deterministic inherited trajectory: not directly tested by the current archive

No current source supplies the clean longitudinal combination needed to observe the deterministic inherited trajectory itself: measured starting genetic/trait distribution, measured visitor regime, repeated inherited trait/genotype change, and sufficient demographic information to separate deterministic selection from finite-population realization.

This is not a reason to resurrect Model 2. The deterministic genotype-density model is a mechanistic comparator whose role is to remove demographic sampling. In nature, its counterpart would require temporal genetic/common-garden or pedigree/selection data rather than another cross-sectional island survey.

### C — finite/history realization: strongly motivated, partially testable

Surtsey, Tiritiri, *Nicotiana*, *Rhabdothamnus*, Mariana and several buffering systems show why chronology, assurance, recovery and demographic persistence are not decorative model extensions. However, none currently closes the full chain from pre-transition state through visitor change, selection, inheritance and finite-population outcome on the same units.

## Reinterpretation of the old 42/37 world layer

The 42 research entries / 37 geographic labels should remain a **breadth and falsification layer**, not 42 attempted Model 3 fits. Its contribution under the unified model is to show that the natural response vocabulary is broad and saturated: partner replacement, sparse pollination, reproductive assurance, buffering, alternative pollinator guilds, disturbance, founding and counterexamples all occur.

The 14 evidence-rich system layers plus direct-history anchors should carry the model-facing projection because they preserve enough mechanistic structure to say where along A → B → C the natural evidence enters.

## Main result of the re-projection

The real-island evidence does not validate one numerical Model 3 trajectory. It does something more useful:

> **Natural island systems already show that similar pollination problems can propagate, branch, be buffered or run counterdirectionally; the unified Model 3 supplies a single mechanistic architecture explaining how those different outcomes can arise at different stages.**

The strongest cross-system alignment is therefore structural rather than numerical:

```text
natural islands
functional composition / access / effectiveness
        ↓
plant-specific response and branching
        ↓
assurance / history / compensation / demographic persistence
        ↓
different realized outcomes

unified Model 3
fixed-state selection branch
        ↓
deterministic inherited trajectory
        ↓
finite/history-dependent realization
```

## What would falsify the unified interpretation

The projection should be treated as a falsification programme. Particularly informative failures would be:

- repeated systems where measured functional mismatch changes strongly but reproductive selection/return is invariant across well-sampled plant states;
- longitudinal systems where deterministic selection predicts opposite directions but inherited change is consistently unrelated even before severe population decline;
- direct partner-loss/recovery systems where history, assurance and demographic state add no predictive information beyond the current visitor environment;
- independent systems where a simple visitor-count metric predicts outcomes after composition, matching and effort are controlled, contrary to the fixed-budget composition result.

## Immediate manuscript consequence

The natural-evidence section should no longer ask whether each island can be assigned to a synthetic `k`, S/C/I regime or Model 2 response class. Instead it should ask which level of the unified Model 3 each source can confront, retain the adverse Dominica result, and use Izu/Ogasawara/Xisha as the strongest contemporary A-layer examples and Surtsey/Tiritiri/loss systems as C-layer history examples.

Claim boundary: this is a reinterpretation of already source-locked evidence. It does not fit Model 3 parameters, estimate natural branch frequencies, establish historical *Bombus* causation, or convert cross-sectional associations into evolutionary trajectories.
