# Repeated outcomes versus repeated clocks in the existing equal-A pilot

**Post-outcome descriptive reanalysis, not confirmation. No new simulation.**
Source and arithmetic are retained in the
[repeatability receipt](audits/CHAPTER2_PILOT_REPEATABILITY_20261019.json).
The source event table was previously checked against the equal-A replay;
this re-pairing does not create another independent experiment.

For each of six founders crossed with six visitor contexts, the original pilot
ran two nested demographic streams under each assurance policy. Pair adjacent
repeat entries within each founder row of the saved event table. A null event
means no closure through census80. All144 paths remained alive.

| Endpoint | Both repeats close | Neither closes | Only one closes |
|---|---:|---:|---:|
| High-I access, fixed A | 14 | 8 | 14 |
| High-I access, evolving A | 25 | 3 | 8 |
| Low-A access, evolving A | 36 | 0 | 0 |

Each row totals36 crossed context pairs, not36 independent island replicates.
Low-A closure means the minimum retained A allele exceeds the founder mean;
high-I closure means the maximum retained I allele falls below its founder
target. Neither is a direct observation of realized restoration success.

For low-A closure, the two event censuses were identical in only1/36 pairs,
despite universal closure by80; absolute timing differences ranged0–32 censuses.
Among pairs where both high-I closures were observed, event censuses differed
in all14 fixed-A pairs and all25 evolving-A pairs. Their timing comparisons
are selected on two observed events and must not be treated as an unbiased
comparison of full closure-time distributions.

The useful distinction is that an endpoint can recur while its clock varies.
This pilot suggests more consistent low-A closure than high-I closure by80
under its particular genetics and costs. It does not establish that assurance
evolution is deterministic or that the I locus is intrinsically more stochastic:
event prevalence, starting allele distributions, target definitions and horizon
differ. Two repeats per context do not measure an exact context-specific event
probability, and finite stochastic variation is not exclusively genetic drift.
No new significance test or confirmatory trait ranking is introduced.
