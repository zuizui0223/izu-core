# 四質問をつなぐ、論文の主張

## 核となる主張

**送粉者不足による花への投資低下には、自殖能力の進化は必須ではない。一方、自殖能力の進化を許すと、送粉環境間の投資差は縮まる。応答の順序、進化の原因、集団存続への利益は、それぞれ区別して評価する必要がある。**

これは、指定したModel3と四つの事前設定の範囲での結論である。比較した両環境には花粉制限があり、送粉が十分な大陸と自然の島の対比を実証したものではない。

## 四質問の役割

| 質問 | 本文で言うこと | 言い過ぎになること |
| --- | --- | --- |
| **閾値** | 送粉条件は誘引投資の繁殖上の見返りを変える。自殖能力を固定しても、低供給側で投資は低下する。 | 自殖が一切なくても同じ、という結論。固定した能力0.5でも自殖は起きる。 |
| **順序** | 実現する順序は遺伝的アクセスと応答の定義に依存する。先行した形質が、後の変化に必須とは限らない。 | すべての送粉条件で自殖先行、または単一の生態学的反転閾値を特定した、という結論。 |
| **実現** | 繁殖上有利な方向と、有限集団で実際に到達する経路は一致しないことがある。決定論とABMの比較は、この違いを示す。 | 差のすべてを浮動に帰属すること。密度モデルをABMの確率的期待値と同一視すること。 |
| **存続** | 繁殖保証・準備状態・発現時期の効果は人口学的条件に依存する。終点で残る確率と、途中まで生き延びる期間も区別する。 | 自然に自殖が先行したこと自体に、将来の存続利益があると断定すること。 |

四つを同格の独立した発見として並べるより、**「花の変化を生む機構」→「その応答順序」→「有限集団での実現」→「集団への帰結」**の順に読む構成にする。ただし、別コホートの結果を一つの因果媒介解析として接続しない。

## 最も強い結果を中心に置く

自殖能力の進化を固定した対照でも、低供給側の投資低下は四設定すべてで支持された。進化を許した場合の環境差の縮小も四設定すべてで支持され、交互作用は+0.1007～+0.2200だった。

**意外性は、縮小が主に「送粉者がより多い側での、追加的な投資低下」から生じたことである。** 相互作用の78～90%がその側に数値上位置づけられた。ただしこれは事後の算術分解で、原因の寄与率を分離した値ではない。固定状態の雌雄リターンの分解は、その非対称性と整合する近接機構として使う。

**自殖能力の進化が投資低下の必要条件か**を、能力の進化を許す／固定する対照で検証したことと、その対照で環境間の最終投資差がどう変わったかを主張の中心にする。過去の応答順序自体を操作した検証ではない。

## 順序について残す結果と限界

今回承認されたI突然変異追加比較は、2創始者背景×9生態条件×128履歴、計2,304履歴の本計算と全件の独立ネイティブ再計算を完了した。8件の元履歴再現も通過した。完了した新規更新は923,216回、経過7,650.664秒で、承認上限内だった。

集計では投資低下イベントが1,138/2,304から1,246/2,304へ変化したが、18セル（9生態条件×2創始者背景）すべての同時区間は0を含み、事前基準を満たす供給・構成による順序反転は確認されなかった。前者は対比較の記述値で、新しい有意差検定ではない。元の結果は保持する。これは反転が存在しない証明でも、効果の同等性でもなく、単一の自然界の閾値を与えない。

二つの独立した保存配列監査も完了し、全2,304新規・元履歴のイベント、18セルの同時区間、親子記録と判定が一致した。追加の生物学的更新は0回。今回の比較は、元の主要結論を置き換える新しい独立確認ではない。
