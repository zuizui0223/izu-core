# Equal-A target-tolerance audit scope

This is a post-outcome sensitivity audit of PR #597, not preregistration or
confirmation. Preserve the original strict-target result and all frozen files.
Replay only its existing 144 paths, with unchanged seeds, native operators and
80-update horizon. Admit the replay only if every original I-loss and evolving
A-loss time and final occupancy matches the retained CI event table.

Before this replay, specify the complete reporting grid: epsilon =
0, .005, .01, .02, .05 on the unit-interval trait scale. I support is absent
when max(I allele) < founder mean I - epsilon - 1e-12. Evolving A lower
support is absent when min(A allele) > founder mean A + epsilon + 1e-12.
Retain extinction as a separate outcome. Report all grid points, founder
targets and strict versus relaxed paired counts; do not select a favorable
epsilon or replace the original primary outcome. Counts are descriptive,
with six crossed founder and six visitor sources, not 144 independent islands.

Retained allele extrema are only necessary bounds on possible recovery;
passing a bound does not establish attainable genotype frequencies, selection,
or actual restoration. The earlier heterogeneous-A eight histories are a
different cohort and are not pooled with this equal-A replay.

For cost-free delayed selfing, inspect the native analytic gradient at fixed
resident state with pollen discount zero. This is a conditional mathematical
prediction, not an evolved-return experiment. No new founder draws, restoration
futures, confirmatory seeds, or 160x160 execution are authorized by this audit.
