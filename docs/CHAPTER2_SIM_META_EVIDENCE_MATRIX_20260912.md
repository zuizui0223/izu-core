## Metadata positives retained

The chapter should retain positive metadata results only when their role is explicit:

- large partner turnover can occur without a sharply identified richness-collapse effect;
- Izu functional exposure predicts corrected matching under the existing secondary-data analysis;
- the world literature contains documented arrival/reintroduction, buffering and alternative-mechanism cases;
- response channels need not move in parallel.

These observations make the synthetic objects biologically non-vacuous.

## Metadata negatives retained

Negative or adverse results are equally important and must stay visible:

- no formal external system closes the full outcome-independent contract;
- Izu matching → pollen is not leave-one-island sign stable;
- the null-corrected historical signed-position projection is unsupported;
- Oshima is a single bridge geographic unit, so a causal Oshima/post-Oshima boundary effect is not identified;
- the broader search reached saturation without closing the missing transition chain.

These failures are not reasons to reopen simulation. They define the correct claim ceiling.

## Writing rule

For each main Results/Discussion claim, write in this order:

```text
synthetic result
→ structural interpretation
→ metadata confrontation
→ claim ceiling
```

Do not write:

```text
synthetic result
→ cherry-picked natural example
→ therefore mechanism validated
```
