1. Q1で「Aの**進化**を固定してもI低下が起こる」は既存の4繁殖条件・別創始者確認で支持。ただし固定発現A=0.5でも自殖は可能。独立創始者8/8は全員で固定Aの遠方投資が低下した指標であり、4/4全条件でA進化による環境間圧縮が再確認されたことを意味しない（圧縮は3/4）。

3. A進化が高Iの喪失時刻を動かすかは、同一創始者×同一訪花者履歴で歴史的A進化可否を無作為割当しないと答えられない。**元Q3はこのA固定／進化対照を備えていない。** 差が実質同等であっても「遺伝的在庫か送粉者消失か」という代替原因は独立に同定されない。

## 事後的な診断の定義

創始者集団の実現した平均花投資を `I_0`、時点tに生存する植物のI対立遺伝子の最大値を `M_I(t)` とする。I表現型は二つのアレルの平均である。

**高I側の構造的除外**

```
L_high(t) = [N(t)>0 and M_I(t)<I_0]
t_high = first t where L_high(t) holds
```

元Q3ではI対立遺伝子集合が子世代で拡大しないため、一度`M_I<I_0`になれば、同じ無I変異・無移入法則下の子孫は**創始者平均I_0への表現型回復が不可能**になる。等号なら高I到達可能性はまだ否定されない。生存時の高I支持喪失と**単一Iアレル固定**、元の低I支援喪失、Q2のA先行イベント、絶滅は別の記録にする。

この条件は遺伝的回復の**不可能性を示す十分条件**であり、`M_I >= I_0`でも適応度・交配・人口減少・有限期間のため実際の回復はできない場合がある。

**ここでのI_0は暫定的な代数上の目標値**。過去の高花投資最適値、実際の送粉者が戻ったときの選択上の最適値、元の失われた送粉サービスという意味ではない。

この元コホートには送粉者の消失を外生的に永久に確定させた時刻`T_E`も、その後に送粉者を復元した確率分布もない。従ってこの探索からは`t_high<T_E`、回復可能性曲線`R(t)`、A進化の`t_high`への因果効果は判定**しない**。
