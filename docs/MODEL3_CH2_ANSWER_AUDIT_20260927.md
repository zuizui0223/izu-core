# Original Ch2 questions versus inherited Model 3: answer audit

Date: 2026-09-27. Source: frozen v2, plus retrospective `model3_ch2_bridge_20260927.json` (all 3,072 transport cases and array hashes verified). This is not a new confirmation cohort.

## What changed in disciplinary emphasis

Model 3 makes pollination, selfing and recruitment explicit, but its headline comparisons initially emphasized reproduction and population recovery. Island ecology is represented by separate visitor/seed arrival, isolation, founding/inherited populations and exogenous community histories. Generic pollinator loss or selfing rescue alone does not identify an island-biogeographic result. The new framing must keep isolation-driven community assembly and repeated-island response distributions as the explanatory problem.

| Does the rank order ensure prediction transport? | Same-regime mean prediction errors about 0.01-0.015 versus cross-regime about 0.14-0.16. | A specific counterexample to using rank agreement as transfer assurance; not all island systems. |

The strongest scientific correction is to stop presenting Model 3's presence of S/C/I or ABM/density comparison as validation of the entire original Ch2 framework. Some questions are answered with new endpoints; two central mechanism controls were absent.

## Concrete next test

Candidate design has 128 new history seeds, eight demographic repeats, three initial investment states, two connectivity levels and four contrasts (natural histories; annually richness-matched; pooled eight-history visitor environment normalized for activity; larger plant capacity only). Total 24,576 cases. The 24-case outcome-blind full-horizon resource pilot passed state validation; projected runtime about 10,415 seconds (2.9 hours), peak resident memory about 76 MiB. These estimates are not biological findings.

Annual richness matching changes identity persistence too; pooled communities change functional composition and averaging, not lifespan. Fixed finite founder-allele support is explicit. A nested-grid test with unchanged initial alleles and no mutation/immigration agrees; this is not convergence from arbitrary continuously distributed founders. Existing mutation/grid failures are retained.

Production must wait for frozen full source identity, runner interruption/reuse tests, prospective analysis and final resource limits. No preferred sign, mixed fraction or ranking is a pass criterion.
