# Q1 — 繁殖保障進化による花投資差の縮小は実装バグか（2026-10-16）

**判定:** 現在の証拠では、**環境間差が縮小したこと自体は元のModel 3の条件付き進化結果として支持される**。しかし、**実装に一切バグがない保証**や、縮小の**長期的・遺伝的因果経路の同定**、自然島嶼への一般化は未成立。**Bug not found** と **mechanism established** は異なる判定。凍結実験や原本を変更しない。

### 新しく追加した負の技術対照（結果が通るまで判断保留）

`test_chapter2_assurance_silent_locus_sham_20261016.py` は、元の4繁殖設定・2送粉環境を用い、8更新だけのモデル内*technical fixture*を比較する。

1. 一方はオリジナル固定A：生殖表現型A=0.5、A対立遺伝子変異なし。
2. 他方は **A対立遺伝子が変異しても、生殖では固定A=0.5を使う**シャム条件。出生に使う元の遺伝子伝達器・乱数系列は同じ。
3. すべての時点で **投資I・マッチングXのディプロイド遺伝子型と遺伝子変異フラグ、個体IDが完全一致し、Aの隠れた遺伝子型だけが異なる**ことを要求。A遺伝子に実際の突然変異が少なくとも1回発生することも要求。

**失敗なら** A表現型固定時にも進化出力が変わるバグの可能性が生じるので、論文への昇格を止めて原因分析へ移る。**成功でも**、短いfixtureで遺伝子座の意図しない混線がないことを示すだけ。元の4設定効果の一般性や、結果の生物学的正当性は確認しない。このテストは新しい科学結果や独立の繁殖履歴標本として数えない。

## バグでなくても結果を誤読し得る重要な前提

1. **共通創始者48個体**：64訪花履歴と8人口反復は独立創始者の反復ではない。ある特定遺伝的構成に依存する可能性を排除できない。
2. **A進化可否は複合介入**：Aの変異・遺伝子型・発現・その後の親選択を変える。「自殖が増えた量による直接媒介」と同一視しない。
3. **near/farはどちらも受粉不足**：nearさえ十分な送粉を受けない。自然島嶼での環境勾配へ無制限に外挿しない。
4. **繁殖設定4つは独立の生態系ではない**：基本Model 3と初期創始者を共有し、無費用遅延自殖は構造的にA増加が有利。
5. **相対的なfar側の投資保持 ≠ farでの投資増大**：元のfarはA固定でもA進化可でも創始者からIが減少。farで相対的にIを維持した動的原因は独立に確定していない。
6. **4設定で符号が揃っても新規理論の保証ではない**：Sakai (1995)は自殖と花誘引資源を共最適化し、Teixido & Aizen (2019)は自然集団で繁殖保障が花サイズへの選択を弱めることを示している。

## 最終処置の基準

- **既存論文で採用可：** 「凍結済みModel 3の4設定では、繁殖保障の進化許可が低・高送粉補充間のI差を縮めた」。CI・技術陰性対照の失敗がないことを前提にする。
- **保留：** 「自殖の進化が必然的に環境間の花を収斂させる」「farでA進化が花投資への選択を高めた」「遺伝的ドリフトがこの現象を引き起こした」「自然島嶼で同じ現象が起きる」。
- **真の機構を確かめる次工程：** 事前に定義した独立の創始者ゲノム集団と送粉環境で、A進化可否×遺伝アクセス×受粉十分の対照を同じ元生殖作用素または独立実装で検証する。新しい生物学的本解析は、既存の失敗・帰無を見た後に有意になる設定を選ぶのではなく、実験デザインと反証判定を先に凍結してから実行する。
