# Model 3 continuum-limit derivation — 2026-10-04

## Bottom line

The current Model 3 deterministic density implementation is **not a PDE**. Its exact continuous-state analogue is a **nonlinear, nonlocal, discrete-time integro-difference / measure-valued dynamical system for sexually reproducing diploid genotypes**.

One component does possess a clean PDE limit: the reflected-normal mutation kernel used in `scripts/model3_island/density.py` is the Neumann heat semigroup on `[0,1]`. For mutation probability `u` and mutation SD `sigma`, the weak-mutation diffusion coefficient per mutable gametic allele is

[

]

A pure trait-density PDE for the full Model 3 requires additional closure assumptions beyond the implemented model, because Mendelian segregation, outcrossing between distinct genotypes, recombination, and global capacity regulation remain nonlocal.

This distinction matters especially for the focal Chapter 2 bridge: its frozen configuration has `mutation_rate = 0`, so the diffusion coefficient is exactly zero. The headline isolation/repeatability results are therefore generated by pollinator-mediated reproduction, inheritance, and finite/density realization, not by a mutation-diffusion term.

would require several extra approximations not present in Model 3:

1. **Local offspring approximation.** Sexual offspring would need to remain close to a single parental trait state. Model 3 can mate distinct parental genotypes and generate nonlocal offspring.
2. **Genotype-to-phenotype closure.** A density over the three expressed means `z` does not retain within-genotype allele pairing, heterozygosity, or linkage information needed for exact Mendelian inheritance.
3. **Linkage-equilibrium / Hardy–Weinberg closure.** The exact diploid distribution would need to be reconstructed from a lower-dimensional allele or trait density.
4. **Weak-selection / small-step scaling.** One reproductive year would need to become a small `dt`; the current reproduction operator can make order-one changes in one step.
5. **Smooth capacity regulation.** The hard global retention factor `min(1, space/total)` would need a continuous-time density-regulation replacement.

Only after those assumptions can a reduced replicator–mutator or Fokker–Planck PDE be proposed.

## 9. The immediate falsification test for a PDE reduction

Do not compare a fitted PDE only to final means. A valid reduction should recover, without retuning per scenario:

1. one-step changes in mean access and investment;
2. one-step changes in trait variance;
3. the sign of the near–far investment contrast;
4. the reversal caused by response-blind visitor-richness matching;
5. the distinction between visitor-history pooling and larger plant capacity where applicable;
6. the persistence/occupancy boundary, or explicitly declare that persistence is outside the PDE state space.

A useful first gate is controlled, occupied, mutation-positive conditions. The focal Chapter 2 bridge is not the correct first diffusion test because `mutation_rate=0`.

## 10. What this means for the island-syndrome claim

The derivation strengthens one point and blocks another.

**Strengthened:** the syndrome-like directional response in the current model is not an artifact of a hand-coded diffusion toward an island optimum. The focal bridge has no mutation diffusion at all. Its coarse floral-investment response emerges from pollinator-mediated frequency-dependent reproduction and inheritance.

**Blocked:** we cannot yet say that the island syndrome has been analytically derived as a PDE attractor. The exact continuum object remains a sexual integro-difference system, and the long-run stationary analysis does not establish a natural attractor.

The mathematically defensible claim at this stage is:

> Model 3 admits an exact continuous-genotype, nonlocal deterministic formulation. Its mutation operator has a Neumann diffusion limit, but the syndrome-generating reproductive mechanism remains nonlocal. A pure PDE is therefore a reduced approximation to be validated, not a relabeling of the existing density model.
