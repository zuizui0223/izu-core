# Model 3 continuum limit and island-syndrome threshold — 2026-10-04

**Status:** exploratory mathematical extension. This does not modify the locked Evolution Letters or Oikos submission surfaces.

## Current result in one sentence

Model 3 does not become a pure PDE in the exact continuous limit: sexual inheritance remains a nonlinear nonlocal integral operator. However, the **mean floral-investment direction admits an exact Price-equation closure**, a reduced continuous phenotype equation recovers the controlled and isolation-driven response structure, and the island-syndrome-like reduction has an explicit marginal-benefit versus marginal-cost threshold.

## 1. Mathematical hierarchy

The work now separates four objects.

1. **Finite ABM**  
   Stochastic individuals, explicit diploid alleles, Mendelian inheritance, finite demographic sampling, survival, immigration and extinction.

2. **Deterministic genotype-density closure**  
   Discrete genotype masses with the same pollination, reproduction and Mendelian inheritance operator, but without demographic sampling.

3. **Exact continuous-genotype sexual system**  
   Replace sums over genotype classes by measures and integrals. The state update has the form

   ```
   n_{t+1}(dx) = s n_t(dx) + r_t [ B_t(dx) + I_t(dx) ]
   ```

   where `B_t` is generated by a nonlocal maternal × paternal × gamete inheritance operator. This is deterministic and continuous in genotype state, but it is an **integro-difference / measure-valued system**, not a pure PDE.

4. **Reduced continuous phenotype equation**  
   Collapse genotype structure to a phenotype density and approximate inheritance locally:

   ```
   ∂p/∂t = (w(z; p, V)/mean(w) - 1) p + D Δp
   ```

   This is the genuine PDE-level reduction. It must be validated against levels 1–3 rather than assumed equivalent.

## 2. Why the exact continuous model is not a PDE

Each plant genotype has three diploid loci. Expressed traits are the mean of the two alleles at each locus.

The reproductive operator contains:

- visitor-specific affinity and functional matching;
- pollen export;
- pollen transfer through visitor channels;
- recipient competition;
- outcrossing;
- delayed or prior selfing;
- inbreeding depression;
- Mendelian segregation at three unlinked loci;
- mutation of transmitted alleles.

For outcrossed offspring, a maternal gamete and a paternal gamete can come from different genotype states. The offspring genotype distribution therefore depends on an integral over **pairs of parental states**.

That nonlocal mating operation survives even when genotype-grid spacing tends to zero. A local second-order differential operator cannot reproduce it exactly.

## 3. The mutation component really does have a PDE limit

Model 3 uses a reflected-normal mutation kernel on the allele interval [0,1]. Its continuous counterpart is the Neumann heat semigroup.

For mutation probability `u` and mutation SD `σ`, the weak-mutation diffusion coefficient per mutable transmitted allele is

```
D = u σ² / 2
```

The numerical audit against cosine eigenmodes of the reflected heat equation showed grid-refinement error decreasing approximately as expected:

```
51 nodes   : 3.13e-5
101 nodes  : 7.83e-6
201 nodes  : 1.96e-6
```

Halving `σ` also reduced the leading weak-mutation approximation error at approximately fourth order.

This validates the mutation-to-diffusion connection only. It does not turn sexual inheritance into diffusion.

### Important focal-bridge boundary

The frozen Chapter 2 isolation bridge has

```
mutation_rate = 0
```

so

```
D = 0.
```

Therefore the headline island-like floral response is **not** generated by a hand-coded diffusion toward an island optimum.

## 4. Exact one-generation mean closure

For the frozen unified-reduction design:

- survival = 0;
- immigration = 0;
- mutation = 0;
- access is fixed within each run;
- assurance is fixed.

Under additive expression, Mendelian segregation preserves the expected parental allele value. The next-generation mean investment therefore obeys the exact Price identity

```
mean(i)_{t+1}
=
mean(i)_t
+
Cov(i, w) / mean(w)
```

where `w` is expected parental-genome contribution calculated from the same Model 3 pollen-transfer and reproductive operator.

This was tested over

```
5 starting access states × 5 visitor communities = 25 cells
```

and the reduced update matched the exact deterministic genotype-density next-generation mean to machine precision in all 25 cells.

So the first moment is not merely qualitatively approximated: under these conditions it closes exactly.

## 5. The second moment does not close by one diffusion coefficient

The same 25-cell audit compared investment variance after the exact Mendelian step with the phenotype-only selection closure.

The inheritance correction to variance was:

- positive in some ecological contexts;
- negative in others.

Therefore one context-independent nonnegative diffusion coefficient cannot exactly represent sexual inheritance.

Mating can average parental states while segregation can re-expand variation. Which effect wins depends on current genotype and mating structure.

This is why the exact continuum theory must retain a nonlocal inheritance kernel, or use a state-dependent moment/QLE approximation rather than a single constant diffusion term.

## 8. Analytic island-syndrome threshold

In the occupied monomorphic reduction with delayed assurance, per-capita parental fitness is

```
w(i) = O0 exp(-c_I i²) [ r + (1-r) q(i) ]
```

where:

- `i` = floral investment;
- `c_I` = investment cost;
- `q(i)` = outcrossed-ovule fraction generated by the Model 3 visitor-matching and pollen-transfer equations;
- `r = a(1-δ)`;
- `a` = autonomous assurance;
- `δ` = inbreeding depression.

Differentiating gives

```
d log w / di = B(i) - C(i)
```

with

```
B(i) = (1-r) q'(i) / [ r + (1-r) q(i) ]
C(i) = 2 c_I i
```

Hence

```
B(i) > C(i)  => floral investment increases
B(i) < C(i)  => floral investment decreases
```

No island label, distance coefficient, or island optimum appears in this equation.

Isolation can create syndrome-like floral reduction only by changing the visitor environment enough to reduce the **marginal pollination return** `B(i)` below the marginal investment cost `C(i)`.

Reproductive assurance can still be used **as a fixed parameter** in this investment threshold: increasing fixed assurance reduces the fraction of fitness that can be gained through extra outcrossing, so the investment gradient can weaken. That comparative-static statement is retained.

### Assurance-selection correction

Do **not** differentiate the monomorphic population expression above with respect to assurance and call the result selection on assurance. That would move the assurance value of the resident population and the focal genotype simultaneously.

For assurance, selection must be defined from a **rare mutant in a resident background** because:

- a selfed seed receives both maternal and paternal gene copies from the focal parent;
- pollen discounting acts through the mutant's paternal outcross success;
- paternal success depends on the resident pollen/recipient environment.

The corrected focal fitness is therefore a parental-genome-equivalent invasion fitness,

```
w_m = 0.5 F_m + 0.5 P_m + S_m
```

where `F_m` is mutant maternal outcross seed, `P_m` is mutant paternal outcross success, and `S_m` is viable selfed seed. The assurance gradient is the derivative of `log(w_m)` with mutant assurance changed while resident traits and the resident pollen environment remain fixed.

Consequently, the earlier monomorphic `r*` calculation is **retired as an assurance-evolution threshold**. It remains only a sensitivity statement about how fixed assurance changes selection on floral investment.

The joint investment–assurance extension is now governed by the frozen rare-mutant contract in `data/design/model3_joint_syndrome_rare_mutant_20261004.json`. Its selection-gradient shift, multivariate Price response, and finite realized trajectory are adjudicated separately.

## 10. What the mathematics now says about an island syndrome

The strongest validated result before the rare-mutant assurance extension is not “a PDE reproduces the simulation.”

It is:

> A pollination-mediated island syndrome can emerge without an imposed island optimum. Isolation changes visitor opportunity; this changes the marginal reproductive return to floral investment. When that return falls below marginal investment cost, selection moves toward reduced floral investment. The sign and regime structure survive from the exact reproductive operator into a reduced continuous phenotype equation and are reproduced across all 128 frozen island histories. Sexual inheritance is then required to recover the full magnitude and variance dynamics.

This gives a layered mechanism:

```
isolation
   ↓
visitor abundance / composition / history
   ↓
marginal pollination benefit B(i)
   ↓
B(i) - C(i)
   ↓
direction of floral-investment selection
   ↓
nonlocal Mendelian inheritance
   ↓
inherited trajectory magnitude and variance
   ↓
finite demography
   ↓
realized island phenotype
```

## 11. What is still not established

Do not claim yet that:

- Model 3 itself is a pure PDE;
- an island syndrome is a universal equilibrium or attractor;
- the reduced PDE reproduces diploid genotype frequencies or heterozygosity;
- natural evolutionary rates or effect sizes are calibrated;
- natural island distance is numerically represented by the synthetic distance parameter;
- the 128 synthetic visitor histories establish natural prevalence;
- the historical-repeatability result has been reduced to a PDE;
- flower colour, corolla dimensions or selfing rate have been quantitatively reproduced.

## 12. Current mathematical conclusion

The current defensible statement is:

> **The Model 3 island-like floral response has a genuine continuous mathematical backbone. Its coarse direction is generated by an explicit pollination-benefit versus investment-cost threshold and survives a reduced continuous phenotype equation across controlled and frozen isolation regimes. The exact continuum theory remains nonlocal because sexual inheritance cannot be collapsed into a single diffusion term.**

This is stronger than calling the discrete density model a PDE, and stronger than saying only that the ABM happens to generate a floral island syndrome.
