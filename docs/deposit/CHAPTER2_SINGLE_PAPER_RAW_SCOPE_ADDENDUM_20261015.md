## Scientific and confidentiality firewalls

1. A GitHub release or a user Library archive **is not** a public DOI, Zenodo deposit or independently governed preservation. No new original bytes were moved in this audit.
2. The **520/521** previously verified private external demographic Actions ZIP readback count is **not** raised to 521 by locating an original GitHub copy of `chapter2-k48-future-shard-18.zip`. The safety-stopped transfer remains blocked; do not bypass it. Existing same-provider source backup remains intact.
3. Four original demographic cohorts, Q4 S33's 32 histories, Q1's 64 histories with eight nested repeats, Q3's 2,304 source cases, and other conditioned mutation histories **are not exchangeable independent observations**. Archive counts and case counts cannot be pooled statistically.
4. An author/depositor must approve creator order and identifying metadata, data/code licensing, access/embargo and actual version before any real Zenodo draft or upload is authorized. Published Zenodo metadata are public even for restricted files.
5. The original Zenodo preflight's `source_main_commit` is a historical provenance marker. The exact 2026-10-15 current main manuscript should be pinned separately at deposit time; do not rewrite old checksums or claim the old preflight already knew about S33.
6. Paper and review-package tests passing means the numerical **readouts and scientific boundaries** are consistent, not that the full underlying 33-section SI source universe has been cross-host re-downloaded and verified.
