## 2. 年内・世代間の因果グラフ：どこが循環でどこが循環でないか

元の実装内では、個体数と表現型は以下の順序で更新される。

```text
訪花者履歴V_t（外部到着・消失、植物状態には依存しない）
      + 既存個体のディプロイド状態G_t
                    |
          形質I・A・マッチングX
                    |
          花粉輸出、機能一致、受領P_t
                    |
          胚珠資源と外交配F・生存可能自殖S
                    |
  親別繁殖重み W_i = (F_i + paternal_i)/2 + S_i
                    |
       有限出生Poisson → 母父の抽選
                    |
     3座位メンデル遺伝／出生突然変異
                    |
          集団容量Kで採用・次代G_(t+1)
                    |
             次期の花形質・繁殖
```

- **許容される世代間フィードバック：** `G_t → pollen/fitness_t → G_(t+1)`。これは時間を伴う生態進化フィードバックであり、同じ時刻で結果を入力へ循環させた誤実装ではない。
- **存在しない訪花者フィードバック：** 花への投資が`V_(t+1)`の到着/存続を変える経路は**実装されていない**。`history.py`は外部のvisitor arrival/lossで訪花者状態を生成する。よって「花縮小→訪花者絶滅→さらなる花縮小」という送粉者動態の自己増幅/共絶滅ループは、この実験から導出できない。
- **Pythonの読み込み循環：** 21モジュールのモジュール最上位の相互インポートはDAG（回帰テストを追加）。`density_step()`内のテンソルバックエンドは関数内遅延読み込みで、`tensor_density.py`が`density.py`を読み込んでも起動時のインポート循環にはならない。
- **統計的な循環論法の危険：** Q1→Q2→Q3→Q4が一つの因果連鎖を示すように書くこと。異なる乱数履歴・遺伝状態・操作／推論単位を持つQ1〜Q4を連結して媒介率にすることはできない。Q4の占有をQ3の実現の帰結として割り付けない。

## 4. 数値・ソース会計の主要検証

**Q1: 登録実験の推定量**は `D=[I(E,far)−I(E,near)]−[I(F,far)−I(F,near)]` である。ここでEはA進化可能、FはA能力固定0.5。全64履歴の4比較セルに入れ子8反復が維持され、原本分解と報告値は次のように同じ。

| 繁殖設定 | E−F near | E−F far | 差 `(far)−(near)` | 登録95%履歴bootstrap |
| --- | ---: | ---: | ---: | --- |
| 遅延自殖 | −0.125323 | +0.035216 | +0.160539 | [0.141824,0.178861] |
| 先行自殖 | −0.198549 | +0.021466 | +0.220016 | [0.202526,0.238256] |
| 花粉割引 | −0.169919 | +0.021582 | +0.191501 | [0.176168,0.206852] |
| A費用 | −0.078915 | +0.021834 | +0.100749 | [0.084194,0.117733] |

本監査で保存された`near/far E−F`から**独立した減算方法で上記`D`を再計算し、元の登録readoutと絶対1e−12以内で一致**。一方、分解と登録値は同じ原8,448軌跡に由来し、**2つの独立生態学的追試ではない**。ゼロ突然変異の全128ペアは完全一致、全登録群は時点1000で生存。

遠方のE−Fは正だが、**創始者から見た遠方のIは両モードで減少**。同じ群を固定した`A↑`の局所I選択勾配は遠方でも負で、終点の正のE−Fと**評価量が異なる**。この違いはQ1の長期機構が未同定であることを示すが、算術上の矛盾ではない。数値を作るバグや、ゲノム再演の不一致は確認されていない（前回の[重点バグ診断](CHAPTER2_ASSURANCE_ATTENUATION_BUG_TRIAGE_20261016.md)は別PRで作成済み。main未統合なら参照の可用性を確認する）。

**Q2:** 51/64のA-firstは遅延自殖・費用ありで、先行自殖では30/64。到達の0.05閾値・20連続センサス・近同時±5の指定がある。A-firstが多いことはAの変異が投資の縮小に**必要**である証明ではない。

**Q3:** 決定論のdensityには有限個体ごとの自己花粉除外の差があり、数値格子収束の成功と、有限集団の同じ応答順序の実現は別。原born-mutation比較320履歴・対象2状態の3/32,2/32と、別コホートの2,304中703の遺伝アクセス喪失を**単一の因果的観測系列に合成しない**。

**Q4:** 32の訪花履歴×元の固定した全ストレス条件の+10.84ppと、64新履歴でB48を固定した容量の+0.775ppは**独立の設計・異なる評価量**。自然に生じたA-firstそのものが絶滅を防いだ結果ではない。Q1の進化実験では全主要腕の占有が1.0なので、**そのQ1実験の中で進化→絶滅の媒介効果は推定できない**。

## 5. 「循環論法・見かけの独立確認」の禁止表現

| 避ける説明 | 理由 | 実際に言えること |
| --- | --- | --- |
| 「花投資低下→送粉者喪失→さらに花投資低下を証明した」 | 訪花者個体群へのフィードバックがない | 外生の訪花者減少が植物の受粉と進化に影響する指定モデル |
| 「決定論と有限ABMは作用素が完全に同じなので差はドリフトで説明できる」 | 個体単位の花粉自己排除・非線形密度規制が異なる | 同じ形質・出生規則を基礎にした、**条件付きで非同一**な並行表現の間の不一致 |
| 「A-firstが増えたのでI減少の原因はA進化」 | 観察順序は必要条件でも媒介分析でもない | Aを固定してもIが減少する登録対照が存在 |
| 「Q3の703例がQ1の環境差圧縮の原因だ」 | 別遺伝子型・別介入・別推論単位 | 特定の新たな形質応答への遺伝的アクセスが失われ得る |
| 「Q4の存続効果は過去だけのA進化の遺産」 | 将来も同じA modeを継続 | 過去×将来を含むA進化モードと過去環境の交互作用 |
| 「nearは自然の本土、farは伊豆諸島」 | 合成距離・合成visitor補充、両方花粉不足 | 指定した2つのモデル訪花者環境での実験 |
| 「独立した4設定×512反復で2,048独立島が支持」 | 同一創始者、各訪花履歴に8人口反復 | 64独立訪花履歴による4繁殖設定の条件付き結果 |

## 7. 残るレビュー課題／投稿への条件

1. **外部の創始者遺伝子型**（本来は独立に抽選・設計した複数の初期ゲノム）でQ1の圧縮の符号が反復するか。64の訪花履歴増加だけでは創始者一般性をテストできない。
2. **生物学的作用素の感度**：2エピソード・花粉受領曲線・Aの近交弱勢/資源配分、訪花者外生性を変えても強い結論が維持されるか。パラメータの感度は新規の凍結設計で管理すべきで、結果を見てから都合のよい設定を選ばない。
3. **Q3/Q4の遺伝的媒介**：同じゲノム・生殖・容量・未来環境での反実仮想を事前指定して同定する必要があり、保存原本からの回顧的会計だけでは寄与率を同定しない。
4. **学術的な主張と再現性の分離**：源SHA・ZIP原本の認証は計算の来歴を保証するが、生態学的正しさの外的検証とは別。Raw external DOI・著作権・ライセンスの公開許可は[Issue #436](https://github.com/zuizui0223/izu-core/issues/436)の継続課題。

**総括:** 最も実証の強いQ1の**差の縮小**はモデル内で数値・コード会計の整合がある。しかし、その原因・自然島嶼への外挿・Q1→Q4の歴史的因果循環は確定していない。Q2/Q3は独立の遺伝的実現を説明する価値があり、Q4は条件付きの人口学的結果として区別して報告する。この区別を維持した一本論文なら、概念的な自己矛盾は回避可能である。
