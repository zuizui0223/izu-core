# アイランドシンドロームの問題と機構の到達点

島の植物は、なぜ繁殖を自分で保証する方向へ変わり、花への投資も変わるのか。その変化は、どの地域・集団でも同じように起こり、集団の存続まで助けるのか。

**研究全体の答えは、隔離に伴って繰り返す繁殖上の制約と、それに応じる複数の経路を示し、さらに「有利な形質変化」と「有限集団で実際に実現する変化」を分けたことにある。** 自然の島で起きた歴史的因果を一続きに説明し切ったわけではない。

## 研究を読む順番

| 生態学の問題 | 解くための比較 | 得られた知見 | 到達点 |
| --- | --- | --- | --- |

| 同じ隔離勾配に繁殖上の制約があるか | 独立した2,969件の花粉添加実験 | 主解析で隔離と花粉制限に正の関連。事後の沖合のみの解析でも正 | 制約の独立した証拠 |

## 全球解析が解いたこと

島と本土の二分だけでなく、隔離の勾配に沿って、島の植物相と独立した花粉添加実験を対応する問いとして調べた。主解析の花粉制限の距離係数は0.09191、P=0.01594。沖合のみの事後解析は0.22031、P=0.02459だった。実験の測定定義を限定すると支持が弱まる感度もある。

重要なのは三つの関係が揃うことである。

- 隔離が大きいほど、繁殖・花形質の組成が変わる。
- 隔離が大きいほど、独立の実験データで花粉制限が強い。
- 繁殖保証・アクセス性の高い形質状態は、現在の花粉制限が低い。

この三角形は「共通の制約に対する機能的な応答」という解釈を支える。しかし、現在の関連から、過去の送粉者減少が個々の形質進化を引き起こしたと同定したものではない。植物相の違いには、種の到着・定着・消失と島内進化のいずれも関わり得る。

**「花は全地域で一様に地味になる」より、「繁殖機能の反復性は、見た目の反復性より強い」が現行の実証結果に合う。** 自家和合性の増加は4地域で再現する一方、単色化は地域限定、浅い・開いた花筒は地域間で逆方向の応答もある。7形質を統合した単一の「地味さ」の効果は現行H1の推定対象ではない。

自殖関連形質を調整してもアクセス性と隔離の関連が北部高緯度・熱帯の主解析で残る。ただし熱帯のDirect-only感度はFDR基準を通らない。これは自殖だけで説明し尽くせない花の再編を示唆するが、送粉者の置き換えという原因を直接測定したものではない。自家和合性自体と花粉制限の関連も不精確であり、自家和合性・実際の自殖・繁殖保証を同義にしない。

根拠：[現行実証原稿](https://github.com/zuizui0223/island/blob/2a1fd0591bf31a3aea2cd217cbe8e76886490eb0/submission/chapter1_current/MANUSCRIPT.md)、[実証とモデルの対応](MODEL3_Q1_MECHANISM_MAP_20261005.md)。

## モデルで解いた利益と費用の問題

モデルは、自殖能力Aと花への投資Iを、遺伝する別の形質として扱う。Iには他殖の母性・父性リターンと資源費用、Aには繁殖保証と近交弱勢・設定別の費用がある。方向を指定しない突然変異、遺伝、生殖、有限の加入を経て形質が変わる。利益・費用の式は仮定であり、その存在をシミュレーションで発見したわけではない。

**第一の経路は、送粉機会の減少によって誘引への見返りが下がること。** Aを0.5に固定しても低供給下でIは低下した。したがって、Aの進化はI低下の必要条件ではない。ただし自殖そのものを除いた実験ではない。

**第二の経路は、繁殖保証能力の変化が花への投資の見返りを変えること。** 元の固定創始者の4設定では、Aの進化を許すと供給環境間のI差が縮小した。局所的なリターン解析は、他殖の利益が残る高供給側ほど、A増加で母性他殖・父性花粉輸出の価値が失われる説明を与える。これは局所機構の説明であり、全期間の終点差を唯一の原因へ分解した証明ではない。

独立した8創始者ゲノム × 8訪花者履歴の追加試験では、縮小は遅延自殖・先行自殖・花粉割引の3設定で登録基準を通過した。A直接費用ありは+0.04427、95%区間−0.04406〜+0.13084で未確定。全4設定を要求する試験全体の判定も未確定である。

高供給側の追加的I低下は新しい4設定すべてで残った。一方、低供給側の相対的I温存は2設定で逆符号になった。**「高供給側が下がり、低供給側は必ず縮小が止まる」という一般法則は採用できない。** 新試験は創始者と訪花者履歴の両方が異なるため、逆符号の原因を創始者だけに帰せない。

根拠：[原4設定と各発見の証拠](CHAPTER2_EIGHT_FINDINGS_INDEX_20261016.md)、[独立創始者試験の全結果](CHAPTER2_Q1_FRESH_FOUNDER_RESULTS_20261016.md)。

## 選択上の有利さと進化の実現を分けたこと

ある形質が先に変わったという観察は、それが後の変化を引き起こした証明ではない。A先行は元の特定設定で51/64履歴だったが、別設定では多数派として確認されず、A進化を固定してもI低下が生じる。

また、同じような平均表現型でも、保有する対立遺伝子やその配分が違えば、到達できる形質と順序は異なり得る。決定論がA先行を予測した二つの低供給条件で、有限集団は3/32、2/32履歴のみ同じ分類になった。全履歴が200更新まで存続しており、絶滅だけではこの不一致を説明できない。両条件とも平均Iは低下しており、「進化が全く起きなかった」わけでもない。

別の遺伝子型追跡では、追加的なI低下に必要な遺伝的支持が、全固定より前に失われる例を確認した。これは突然変異・移入によるI変異の補充を置かない条件の結果である。決定論との不一致をこの喪失だけで説明した媒介分析ではない。決定論と有限モデルには構造差もあり、差をすべて純粋な浮動に帰すこともできない。

島嶼生態学への含意は、**集団が残ること、有利な形質が存在すること、その形質に到達できることは別の条件である**、という点にある。実際の小島で同じ制約が働くかは、自然集団の遺伝・送粉・履歴データによる検証対象になる。

根拠：[有限集団での実現](CHAPTER2_Q3_FINITE_GENETIC_ACCESS_AND_REALIZATION_20261015.md)、[原本ごとの機構の区別](CHAPTER2_Q3_SELECTION_REALIZATION_SOURCE_MAP_20261015.md)。

## 生物多様性と存続について答えた範囲

別設計の負荷実験では、A進化可能性などの操作に条件付きの占有効果がある。しかし、自然に自殖能力が先行して進化したから絶滅を回避した、という経路は識別されていない。個体の繁殖利益、花粉制限、加入、集団占有は別々の指標である。

この研究が直接扱うのは、植物相の形質組成と、モデル内の繁殖・遺伝・集団占有である。自然の島の種数、群集全体の絶滅率、相互作用網の安定性まで予測したものではない。生物多様性研究への貢献は、同じ隔離圧の下で、機能が繰り返しても形態と進化経路は揃わない理由を検証可能な問題にしたことにある。

根拠：[人口学的効果と限界を含む発見F7](CHAPTER2_EIGHT_FINDINGS_INDEX_20261016.md)、[四質問の論理監査](REPOSITORY_REVIEW_LOGIC_20261016.md)。

## アイランドシンドロームをどこまで説明したか

| 機構の段階 | 現在の判定 |
| --- | --- |
| 隔離に伴う繁殖機能と花形質のパターン | 全球の関連を提示。全形質の一様な変化ではない |
| 独立した花粉制限の勾配と形質の機能的関連 | 支持。ただし過去の因果方向は未同定 |
| 投資低下にA進化が必要か | モデル介入で不要と確認した条件がある |
| A進化が環境間の投資差を変えるか | 元の4設定で確認。新背景では3設定支持、1設定未確定 |
| 遺伝・有限集団が進化の実現を制約するか | 特定条件で確認。全体差の原因別寄与は未分離 |
| 自然の島の地域差を、送粉者減少・置換・定着・進化へ分解 | 未解決 |
| 自然な形質進化の順序が多様性維持や絶滅回避を生むか | 未解決 |

**総合結論：隔離に伴う共通の繁殖制約と複数の形質応答を示し、繁殖保証と花投資の共同変化が利益・費用および遺伝的実現条件に依存することをモデルで具体化した。アイランドシンドロームを固定した形態の一覧から、機能・形成経路・実現条件の問題へと整理できる。** この概念的統合は、別々の実証・モデル実験を一つの自然史的因果鎖として証明したという意味ではない。
