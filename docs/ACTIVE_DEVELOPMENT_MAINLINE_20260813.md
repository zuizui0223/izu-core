## Current primary question

> Why does island-associated simplification or reorganization of pollinator function produce divergent plant responses rather than one universal post-establishment trajectory?

The ecological hypothesis is that the same broad perturbation can generate different outcomes because lineages enter it from different functional starting states and because local interaction context changes how the perturbation propagates downstream.

External island systems are comparative held-out response-state challenges. They do not choose seeds, parameters or mechanisms.

## Ecological synthesis

The paper now argues for a **state-dependent island-response view**:

```text
island-associated pollinator functional simplification / reorganization
        -> lineage-specific functional starting state
        -> branching or same-direction response
        -> local context reallocates / rescues / worsens branches
        -> reproductive filters attenuate downstream consequences
```

This is not a claim that classic island syndromes are wrong. Macroecological syndromes can arise from colonization filtering, differential persistence and aggregation across lineages. The present study addresses the post-establishment ecological response: an aggregate island syndrome does not imply that every established lineage follows the same trajectory.

## Role of state separability

State-separability analysis remains in the repository, but it is a **supporting inference guard**, not the paper's primary novelty. It is used to prevent overinterpretation of response labels:

- same-direction response does not prove uniform starting states;
- attenuation does not uniquely identify assurance versus network context;
- external state compatibility does not identify the real-world causal mechanism.

Detailed sensitivity/specificity diagnostics should move mainly to Supplementary material.
