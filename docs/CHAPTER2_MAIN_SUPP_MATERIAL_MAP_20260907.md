## Paper-facing rule

The main paper carries only results that change the inferential argument. Supporting Information carries complete parameterization, sensitivity surfaces, source-readiness matrices, search-tranche provenance, structural attacks and leave-one-unit diagnostics.

The paper remains a four-act argument:

`relational response geometry -> world confrontation -> identifiability bottleneck -> Izu continuity-system resolution`

The prospective visitor-effectiveness / reproductive-dependency / mature-output experiment is an empirical extension motivated by the final measurement contract. It is not a prerequisite for the present paper and is not used as retrospective validation.
