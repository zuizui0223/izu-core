# Chapter 2 Q1 — 独立創始者ゲノムによる環境間花投資差の再検証（2026-10-16）

**科学的地位：新規・独立創始者ホールドアウトの事前凍結設計。結果は未取得。旧Model3の同一繁殖・遺伝方程式を使用するため、独立の生態学モデルの外的検証ではない。**

## 中心となる反証可能な質問

元の登録8,192軌跡で、繁殖保障能力Aを進化可能にすると、遠い/近い訪花者補充の間の花投資Iの最終差が四つの繁殖設定すべてで縮んだ。しかし64の訪花者履歴と8回の人口抽選反復は、**一つの創始者48個体のディプロイド遺伝子型**からの反復であり、創始者ゲノムの違いは推論できない。

ここでは**初期ゲノムの乱数を新しく独立に引き直し**、同じ元生物モデルのもとで、この符号の安定性を調べる。質問は「花投資差の圧縮が普遍的なのか」でなく、「元の初期ゲノム一組だけに依存しないか」という狭い堅牢性検証である。

## 事前推定量・支持/反証判定

各繁殖設定 s・創始者 f・訪花者 h の4本の対応軌跡から

\[
D_{s,f,h} = (I^{E}_{far}-I^{E}_{near})_{s,f,h}
            -(I^{F}_{far}-I^{F}_{near})_{s,f,h}
\]

を更新1000で計算する。Eは繁殖保障Aの進化を許す介入、FはA遺伝的進化を禁じた介入（自殖自体は可能）。**D>0は元のfar−near投資差を縮める方向**。遠側の花投資が創始者より絶対増加する意味ではない。

- **仮説支持:** 1,088本すべての源・ハッシュ・時点1000トレースが揃い、32組のゼロ突然変異完全一致・1,024本全生存。4つの繁殖設定**すべて**でD全平均>0、創始者と訪花者を**別々に再抽選する二元交差bootstrap**の95%区間下限>0、8創始者組中6組以上でその訪花者平均D>0。
- **符号反証:** 有効な実験・陰性対照のもと、どれか1繁殖設定のD全平均が0以下。結果を隠さずすべて残す。
- **判定保留:** 途中打ち切り、終点絶滅によるIの欠測、ゼロ変異不一致、ある設定の区間が0に重なる、6/8創始者の頑健性閾値を満たさない。1000更新以降へ延長・履歴追加・モデルパラメータ調整して「有意」にすることは禁止。
- bootstrapは9,999回、seed 5606162026、訪花者履歴と創始者をそれぞれ8個から復元抽出。8×8の対応行列を使う。**64セルを独立母集団とみなす普通のbootstrapは禁止**。4設定は連言で一括判定し、各設定の点推定、区間、創始者別8値、訪花者別8値を全件表示。
- 1つでも人口が終点絶滅した場合、占有率は報告する一方、絶滅したIを0に置換せず、主要D判定は**保留**。生存個体群だけを選んで符号を決めない。

## 言えること・言えないこと

成功した場合に限って、「**元のModel 3の4繁殖設定で、独立に引き直した初期ゲノム8組でも、A進化を可能にしたことによるfar−nearのI差縮小の符号が維持される**」が支持可能。独立創始者から抽選した8組という分散構造を示し、元の一ゲノム依存性の懸念を減らす。

なお、これは**生物学的作用素の独立検証ではない**。花の大きさや自殖率の野外実測、島ごとの適応速度、自然の高送粉者環境、共進化した訪花者個体群の適応度や集団絶滅を予測したことにはならない。失敗した場合も元の事前凍結Q1登録結果の計算正否と、この新創始者背景への一般化を分けて報告する。
