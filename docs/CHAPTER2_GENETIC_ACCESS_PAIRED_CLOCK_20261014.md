## 全768ペアの打切りを保持する追加診断

上の「両条件で検出」の時刻差には、検出されたという事後条件付けがある。そこで**全768ペアを分母**に、200更新・201センサスのうち20連続判定を満たせる最終開始年181より先／未検出の場合だけ、**182を解析上の固定上限コード**として時間を切り詰めた。これは将来のイベント発生年を182と予測する操作ではない。

\[
T^*=\begin{cases}
T_{\mathrm{first\ sustained}},&T_{\mathrm{first\ sustained}}\le181\\
182,&\text{未検出}
\end{cases},\qquad
\Delta T^*=T^*_{\rm H}-T^*_{\rm L}.
\]

- **A:** 全768対応ペアで \(\overline{\Delta T^*}=-51.3021\) 更新。初回応答開始が25更新以内の個体群は、低幅 **134/768**、高幅 **701/768**。50更新以内は低幅 **362/768**、高幅 **762/768**。
- **I:** 全768対応ペアで \(\overline{\Delta T^*}=-2.5130\) 更新。初回応答開始が25更新以内は低幅 **303/768**、高幅 **308/768**。50更新以内は低幅 **416/768**、高幅 **429/768**。
- 年10/25/50/100/150/181の両処理の全開始累積検出件数を同じJSONに保存した。A早期化は「双方で検出された742件」のみに限定した集計上の見かけではないが、**固定イベント判定の早期化**であって自然選択開始の直接測定ではない。

## 解釈と限界

1. **言えること：** 原モデルの固定判定規則・2創始者背景において、A半幅の拡大はAの「発生率」より**検出された持続的A応答の初開始時刻**を大きく早め、六分類の相対順序を組み替えた。単なる新規Aイベントの26増分だけではD差を記述しきれない。
2. **言えないこと：** 「選択が47更新早く始まる」「速度が変異量だけで因果的に決まる」「自然島嶼定着で必ず同じ」「Q4存続を救う」。0.05・20点窓・200更新 horizon の閾値幾何学はA幅介入の効果に含まれる。元の別閾値0.10では順序帯の解釈が変わる。今回の6記録は0.05の初開始情報しか持たず、0.025/0.10で再分類するには生の**毎年201時点×各個体群**が必要。
3. **検出条件付きの選択：** 「両群でAイベント検出」の742組や「両群でI検出」の375組だけの時刻差は、事後条件付きであり、全768組に対する純粋な媒介推定量ではない。全開始分母の6分類と検出率を必ず並置する。非検出は欠測・検出不能として残し、時刻181より先のイベントを「変化なし」にしない。
4. **独立単位：** 既存名目上の将来乱数128クラスターは独立な遺伝的供給源128個ではない。独立創始者2背景の一般化可能なSEやp値、機構の媒介割合は計算しない。元パイロットの0.0363というSEを新たな創始者確認の検出力に流用しない。
5. **対象介入の分離：** [PR #512](https://github.com/zuizui0223/izu-core/pull/512)の創始者瓶首と[PR #519](https://github.com/zuizui0223/izu-core/pull/519)のm0対m12共保有実験は**異なる操作**。このA半幅診断をそのまま共保有・瓶首・Q4の長期効果とみなさない。
