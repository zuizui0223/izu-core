# Model 3 — PDE / ODE / SDE / SPDE の数学的地位（2026-10-16）

**判定：中心の決定論的 genotype density はPDEではない。元の有限ABMもSDEではない。** 既存のODE・PDEは別途条件を課す縮約・突然変異近似である。全3座位のModel 3を置換できる連続時間SDE/SPDEは現在未検証。これらは同じ生物学的モデルの異なる数理表現であり、4つの独立した生物学的確認ではない。元の凍結計算は一切変更しない。

## 2. 階層を混同しない系統図

    元の生殖・3座位遺伝モデル
       +-- 有限ABM（離散世代、確率出生・有限個体）
       |     +-- 有限整数genotype-measure Markov過程（限定条件で等価）
       |     +-- 一代Gaussian/CLT近似（一部で精度確認）
       |     +-- SDE/SPDE（全面代替は未検証）
       +-- 決定論的 genotype density（離散世代、非線形）
             +-- 連続アレル：非局所性生殖の積分差分演算子
             +-- 出生突然変異の局所極限：熱PDE成分
             +-- 表現型縮約map → replicator ODE近似

有限ABMとdensityの違いを「ドリフト成分」と呼び替えない。densityは有限ABMの条件付き期待値と同一ではないため、単一差だけからドリフトの割合を特定できない。

## 3. 実際の数値・失敗を保持

1. **ODEの限定された成功**：固定環境25セルの更新60で性生殖密度と縮約ODEの方向25/25、平均絶対誤差0.004337913、最大0.01234168。更新200で平均0.000897042、最大0.006333844。条件付きの方向精度であり、全3座位・正の突然変異を含む完全同値性ではない。
2. **形質だけでは遺伝を閉じられない**：0.5/0.5のホモ接合と0.4/0.6のヘテロ接合は同じ発現平均0.5でも、次世代分散がそれぞれ0、0.005。現在の表現型だけのODEが両方の将来遺伝的分散を再現することは不可能（他の遺伝状態を保持する場合を除く）。
3. **変異だけのPDE**：元の出生突然変異は (1−u)Identity + u H(sigma²/2)、拡散近似は H(u sigma²/2)。Hは反射境界の熱演算子。固定幅の稀な突然変異は一般に非局所ジャンプ過程であり、単純な局所拡散とは限らない。
4. **特定のSDE高速時間極限が成立しない証拠**：訪花者ゼロ、先行自殖、元の8創始者を同割合で複製した厳密例で一世代のドリフトノルムはK=8,16,32,64,128の全て0.00172576304865。したがってK×ドリフトは0.0138061から0.2208977へ増大。元の選択強度のまま dt=1/K とする**普遍的な有限ドリフトItô-SDE極限**は不可能。ただし弱選択、離散時間でのCLT、吸収境界付き測度過程や他のSPDEの可能性は未否定。また自然near/far固定創始者スクリーンは**別の事前判定に不合格**で、事後的に成功と判定変更していない。
5. **一代CLTの狭い成功**：元の有限子孫分布に対する固定Nでの正規近似Kolmogorov距離はN8で0.090104、N128で0.022407。これは3座位遺伝の長期予測や遺伝型完全消失の近似精度ではない。
6. **連続SPDE型の落とし穴**：相対出生確率q=0.02、N=8では有限出生がその遺伝子型を完全に失う確率 (1−q)^N = 0.850763...。同じ平均・共分散を持つが支持を正に保つDirichlet代理過程では0コピー確率が0。
7. **Gaussian＋投影は遺伝子型多様性を誤る**：N8で元の子孫分布からの正確な期待遺伝子型クラス数6.10638に対し、Gaussian＋クリップ＋最大剰余整数化は7.00391。さらに多項抽選すると5.67756となり誤差が逆向き。正規近似の1個の平均形質への良好な適合は、動的な遺伝子型支持を保証しない。
8. **高解像度の旧PDE/密度数値検証の失敗**：旧全3座位の正変異・長期グリッド検証は9→13節点の32ケース中1ケースのみ元の許容誤差を通過し、1000期の高解像度検証は未決で停止。別の10条件・257節点のQ3 density比較は条件付きで採用されたが、以前失敗した全モデルの収束を遡及して救済しない。

## 4. 因果循環・数学的な誤同定の防止

- 進化圧と遺伝状態は時間を介して相互作用する。これは世代間の**正当なフィードバック**であって同一時点の循環依存ではない。
- Model 3の訪花者の更新は植物の花の進化を入力としない。**花の縮小 → 訪花者減少 → 花の縮小**という双方向の共進化ループは実装されていない。
- **Q1～Q4は別実験**であり、ODEで選択方向を説明したことやSDEの数学的反例から、Q4存続への一続きの因果媒介を認定できない。
- 地理的INLA-SPDEによる環境空間効果と、遺伝子型の形質空間SPDE候補は**別の分野・評価対象**であり、一方の成功を他方の検証と呼ばない。
