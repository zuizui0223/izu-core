## Scope

The boundary is a fixed-founder genetic-access transition band, not a universal pollinator-supply threshold. Access preparation changes realized responses and endpoint states; only 42/1,024 versus 43/1,024 preparations achieve both events. Positive registered bootstrap persistence contrasts identify a conditional all-start policy effect. Conservative distribution-free intervals still include zero. Neither pure natural-order mediation nor universal benefits are established.
