# Q2：元Iゲノム固定の共保有0対6 — 1子の全結合分布

**2026-10-15 / 検証対象：元Model3のconfirmation F0を用いた静的初代F1の確率積分のみ。実際の出生・進化未来・新しい供給源ゲノム生成はすべて0。**

## 明確な問い

[PR #525](https://github.com/zuizui0223/izu-core/pull/525) は、元のI相同染色体を固定し、同一M/I/A表現型群のAヘテロ接合保有者だけを交換する制約の下で、mainの最大可能な共保有差が0、confirmationが6と明らかにした。**厳密なm0対m12は元の2供給源では不可能**であり、人工12群×4個体の調整とは異なる。

一方confirmationの同一表現型24個体群（M=0.5625, I=0.5, A=0.5）は、Iヘテロ18個体・Iホモ6個体である。この範囲内なら、6個のAヘテロ接合を全員Iホモから全員Iヘテロへ移して**元Iのコピーを1つも変更せず、m0→m6という元ソースに条件付けた静的反実仮想**を定義できる。

## 原本Aの状態に関する重要な補足

原本の型付きF0を再照合すると、**mainもconfirmationも元のA遺伝子型は48/48個体が0.4375/0.5625のヘテロ接合**で、全員のA発現平均が0.5である。したがって、Aヘテロ接合を6個体へ制限する操作は自然に存在するAの入替だけではなく、**元のAヘテロ接合42個体を各処理で0.5/0.5のホモ接合に人工的に戻す介入**を含む。

このm0/m6は**元のIコピー・Mコピー・成人表現型・初期生殖リターンを保つが、Aコピー全体を人工的に再構成する条件付き技術対照**である。「元創始者の全ゲノムをそのまま移動した」と解釈しない。

## 新しい静的入力の定義

- N0=48、旧confirmationの全M/Iコピー、全48個体のA/I/M発現、人口数、3種の元送粉者文脈（0/3/4）を維持する。
- 元のIホモの6個体（5,13,21,29,37,45）に人工A半幅±0.0625を載せた場合をm0。
- 元のIヘテロの最初の6個体（1,3,6,9,11,14）に同じ人工A半幅を載せた場合をm6。元Iは両腕とも完全に不変。
- 2処理のAヘテロ接合数はともに6、群ごとの成人表現型・A変異幅・親ごとの初期生殖リターンを同じに固定し、同一モデルの母父self/他殖の原native Ledgerから子1個体の全A/I分布（1/32格子）を16コピー組で確率積分する。
- **子を実際に生成しない**。子1個体の全A/I周辺分布が一致したかと、**結合確率分布**の全変動距離を別々に記録する。祖先集団平均との差で同一子がA+0.05/I−0.05へ入る確率も探索的診断であり、人口平均・20センサス持続判定ではない。

## 受入条件

読取専用の `scripts/audit_chapter2_original_confirmation_m0_m6_F1_20261015.py` が元の型付きF0のGitハッシュ、元native Model3のコード、I個体別コピーと表現型の同一性、A各6保有者を検証。原モデルの親リターン行列9種を元F0／m0／m6ですべて照合し、各形質の全F1周辺確率差が1e−12以下である場合だけ受理する。

初代の結合分布が異なっても、符号付きの有利な二遺伝子型が優先されること、適応度が高まること、長期の六分類進化順序やQ4存続が変わることは何も証明しない。元の**main遺伝子型背景ではm0対m6も構成不能**。confirmationの単一ソースから独立島嶼への一般化・CI・有意差も行わない。
