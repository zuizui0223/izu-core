# Chapter 2 NEE pre-data upgrade contract — 2026-09-12

Status: **prospective upgrade lane; does not reopen or supersede the scientifically closed Oikos manuscript.**

## Purpose

The current Chapter 2 paper is closed on a synthetic mechanism claim:

```text
pollinator-community reorganization
    -> conditional response geometry
    -> state x realized-community branch contingency
    -> regime-dependent determinant ordering
```

This file defines the only allowed route for upgrading Chapter 2 before any new focal Izu outcome data are opened. The upgrade must add **prospective natural prediction**, not more post hoc simulation growth.

The current Oikos manuscript remains an immutable fallback. Failure of any upgrade gate cannot be used to alter the frozen synthetic result, retune the model, redefine the field analogue, or change the current Oikos claim ceiling.

## Scientific target

The highest justified pre-data target is a Nature Ecology & Evolution Registered Report only if the Stage-1 package can make a broad, falsifiable prediction that is important regardless of result direction.

The candidate general claim is:

> The ecological outcome of pollinator-community reorganization is jointly determined by pre-outcome plant functional state and the realized effective pollinator community, and the relative contribution of these determinants changes as independent community-exposure opportunities are averaged while relational non-additivity can persist.

This is a natural-system prediction derived from Chapter 2. It is **not** a claim that any field quantity equals synthetic `k`, nor that the synthetic numerical crossover near `k=4` should occur in nature.

## Frozen source result

The pre-data prediction is derived from four source results already closed in `izu-core`:

1. exact realized-richness matching changes coarse ensemble regime but retains strong individual branch contingency;
2. state x realized-community non-additivity persists after richness control;
3. finite-community realization variance declines as independent trajectories are pooled;
4. with active plant adjustment, the ordering of starting-state and community-realization additive contributions reverses across the audited synthetic system-size sequence while mixed branches remain over the finite range.

No new synthetic result is required for the upgrade lane.

## Pre-data natural prediction hierarchy

### P1 — composition beyond amount

After controlling for coarse visitation amount and a predeclared diversity summary, realized **effective-community composition** should retain predictive information for plant reproductive outcome.

Blocked shortcut:

```text
visitor richness alone -> "community state"
```

Primary community representation must retain functional composition or effective-service weighting.

### P2 — plant state x realized community

A pre-outcome plant functional-state vector and the realized effective-community vector should have a non-additive interaction for the reproductive endpoint.

The state vector must be frozen before focal outcome inspection. Variables may be dropped only for prospectively declared measurement failure, not predictive weakness.

### P3 — functional bridge

Differences in visitor composition must connect to biological function through an independently measured intermediate such as single-visit pollen deposition, effective stigma contact, or another predeclared effectiveness measure.

Raw occurrence or visitation frequency alone does not satisfy P3.

### P4 — dependency/fitness consequence

A predeclared dependency manipulation or equivalent causal contrast must establish that variation in effective service can reach a mature reproductive endpoint.

Preferred same-plant treatment family:

```text
open natural pollination
bagged autonomous treatment
hand cross-pollen supplementation
single-visit then bagged treatment where feasible
```

Treatment details, randomization, blocking and any sham control must be fixed at Stage 1.

### P5 — exposure-aggregation prediction

As additional independent community-exposure opportunities are pooled within the predeclared biological unit, the community-realization contribution to outcome variance should decrease relative to the pre-outcome plant-state contribution.

The prediction is **directional and qualitative**. It does not predict a field threshold matching synthetic `k`, and it does not require monotonicity at every adjacent aggregation level.

Relational non-additivity is predicted to remain detectable over at least part of the audited field exposure range if measurement reliability is adequate.

### P6 — transport/replication

At least the P2 state x community prediction should be tested in a second independent natural context when feasible. This may be a second island/system collected prospectively or a genuinely independent public dataset that was not used to define the predictor, threshold or analysis rule.

A second system is an escalation criterion for the NEE route, not a requirement for the current Oikos paper.

## Promotion gates

### G0 — Stage-1 feasibility gate

Before any focal outcome data are collected/opened, freeze:

- research questions and hypotheses;
- primary endpoint;
- functional-state definition;
- effective-community representation;
- blocking and treatment assignment;
- quality-control and exclusion rules;
- sampling/power rule or Bayesian design criterion;
- primary model and contrast family;
- missing-data and failed-measurement handling;
- P1-P6 promotion logic;
- raw-data/code/materials sharing plan.

If G0 cannot be completed prospectively, do not call the project an NEE Registered Report candidate.

### G1 — field identifiability gate

The data must separately identify:

```text
visitor exposure
!= visitor effectiveness
!= reproductive dependency
!= mature reproductive outcome
```

If these collapse observationally, the NEE upgrade fails even if simple visitation correlates with seed set.

### G2 — primary relational gate

The predeclared state x effective-community interaction or equivalent relational estimand must be estimable with adequate support and measurement reliability.

A significant main effect of richness or visitation does not substitute for G2.

### G3 — functional-chain gate

The visitor/effective-community layer must predict the independent functional intermediate in the preregistered direction or otherwise yield a scientifically interpretable falsification.

### G4 — consequence gate

The dependency manipulation/contrast must show whether functional-service differences can alter the mature endpoint under the declared treatment logic.

### G5 — determinant-order prediction gate

The predeclared exposure-aggregation analysis must be estimable. Promotion does not require reproducing the synthetic crossover location; it requires a valid test of the predicted redistribution of variance/contribution with increasing independent exposure aggregation.

### G6 — breadth gate

For the strongest NEE route, either:

- replicate the core P2 relation in a second independent natural system/context; or
- provide a comparably strong external transport test using untouched data and a frozen analysis contract.

## External-public-data lane before own data

Before focal Izu data collection, external public datasets may be screened only for whether they contain enough independent fields to evaluate P1-P4 or a transport version of P2.

Admissible minimum fields for a strong external test:

```text
plant or reproductive unit identifier
pre-outcome plant state or prospectively defensible proxy
visitor identity/composition and exposure
functional effectiveness or pollen-transfer measurement
reproductive endpoint
```

Datasets lacking effectiveness or dependency may still test P1/P2 but cannot be described as completing the causal chain.

### External-data firewall

- define synthetic `k` using a field diversity index;
- promote historical Bombus loss from contemporary associations;
- use Chapter 3 phenotype values as Chapter 2 validation.

## Registered Report route

Current Nature Ecology & Evolution guidance states that Registered Reports are peer reviewed at Stage 1 before data collection, may receive acceptance in principle, and then proceed to Stage 2 after the approved study is completed. A Stage-1 manuscript requires the scientific question/background, hypotheses, procedures, proposed analyses, sampling plan/power or Bayesian equivalent, and optional pilot data, together with commitments to archive data/materials/code and register the approved protocol.

The correct timing for this project is therefore **before focal Izu outcome data collection/opening**, not after a successful field season.
