## Allowed use

These materials may be used to:

- reproduce historical project development;
- audit why Model 2 was retired;
- trace the origin of the ecological-averaging / synthetic-`k` idea;
- compare old service-endpoint diagnostics with later Model 3 controls.

They must **not** be presented as:

- current Supporting Information;
- a second active biological mechanism;
- an unresolved Chapter 2 control gate;
- current-paper evidence for a natural `k` threshold, natural branch prevalence or calibrated island quantity.
