# Legacy archive

Everything under this directory is **historical provenance, not the current Chapter 2 scientific surface**.

Current Chapter 2 lives in the repository root, `docs/`, `scripts/model3_island/`, current Model 3 top-level scripts, and `tests/`.

Archive layout:

- `model2/` — retired response-geometry / synthetic-k / S/C/I model and controls.
- `routes/nee/` — retired Nature Ecology & Evolution route and Registered Report planning.
- `routes/ecology-letters/` — retired analytical Ecology Letters companion route.
- `submission-history/` — superseded manuscripts, narrative locks and journal-routing drafts.
- `model3-development/` — superseded working notes from development of Model 3.
- `pre-model3/` — pre-Model3 top-level scripts and tests that are no longer part of automatic CI.

Legacy material remains available for provenance and historical reproduction. It must not be used as a current manuscript, Supporting Information component, active CI gate, or source of stronger claims than the current Model 3 claim ceiling.
