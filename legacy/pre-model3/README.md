# Pre-Model3 code and tests

Top-level scripts and tests that no longer participate in the Model 3 paper have been moved here to keep the active repository surface small.

They are preserved for provenance only and are intentionally outside `pytest`'s configured `tests/` path.

Current executable code is concentrated in:

- `scripts/model3_island/`
- top-level `scripts/*model3*`
- current Oikos render/build/audit scripts.
