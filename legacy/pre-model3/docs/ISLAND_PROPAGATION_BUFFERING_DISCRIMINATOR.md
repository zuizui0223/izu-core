# Island propagation versus buffering discriminator

Updated: 2026-08-22

## Current decision

The programme has enough contrasting island systems to reject several tempting one-factor explanations of why pollinator-functional change sometimes reaches reproduction and sometimes does not.

The current comparison is:

```text
Ogasawara Psychotria
physical access failure -> directional pollen transfer -> fruit asymmetry
= propagation

Hawaii lobelioids
signed mismatch -> contact/robbing/resource change -> high fruit/seed performance
= buffering

Izu
common-ish matching decline -> divergent pollen / tube responses
= branching

Nicotiana
island selfing/trait difference without detected current service deficit
= assurance / establishment alternative

Guaiacum
strong visitor-environment contrast + negligible autogamy -> similar breeding index
= buffering with no high-autogamy explanation
```

This pattern is already enough to show that one universal `buffering` parameter would be biologically misleading.

## Discrimination 1 — autonomous reproductive assurance is not the universal buffer

*Nicotiana glauca* strongly supports autonomous assurance as a **system-specific** candidate. Island populations have greater autonomous self-pollination capacity, with the strongest value on recently colonized Santa Cruz Island.

But *Guaiacum sanctum* blocks the universal reading. Autogamy produced only a handful of mature fruits and the source concludes that an animal pollen vector is required, yet a very large pollinator-assemblage contrast is accompanied by similar reported self/outcross breeding-system indices.

Ogasawara provides the complementary propagation end member: self fruit set is 0% in both floral morphs in the published table, intramorph fruit set is very low, and a physical service asymmetry reaches field fruit production.

Therefore:

> reproductive assurance may buffer propagation in some lineages, but it is neither necessary nor sufficient as the programme-wide buffering explanation.

Issue #91 remains high-value precisely because direct contemporary dependency in the Izu anchor is still missing.

## Discrimination 2 — physical / functional mismatch does not fix the final reproductive sign

Ogasawara is the strongest access-limited propagation case. The dominant honeybee cannot reach the hidden S-morph stigma; pollen transfer becomes S→L and the accessible L morph has much higher open fruit set.

Hawaii provides the opposite boundary. A source-native signed bill–flower axis predicts pollen contact and nectar robbing, but closely overlapping experiments show that altered resource dynamics can coexist with high fruit and seed performance.

Izu adds a third state: broadly lower matching does not yield one pollen or tube-response sign.

Therefore:

> functional position or access can create branch potential, but it cannot be used as a universal direct predictor of final reproductive direction.

This is consistent with the synthetic v12 result and the failed Dominica signed-position projection.

## Discrimination 3 — partner effectiveness changes branch allocation, not the whole branching architecture

ABM v10 already shows the mechanistic version: changing partner quality under matched upstream networks changes the magnitude of 501/648 reproductive contrasts and flips 17 signs, but does not broaden the positive tail or the number of mixed-sign configurations.

Hawaii supplies an empirical analogue: large differences in interaction quality do not force reproductive collapse.

Thus direct effectiveness is still essential to measure, but it should be interpreted as a branch allocator / propagation input rather than the sole generator of response heterogeneity.

## Discrimination 4 — a current service deficit is not required for an island trait difference

*Nicotiana* is the critical case. Island populations have longer corollas and greater autonomous selfing capacity, but the source does not detect lower current island visitation or pollen transfer, and island fruit set is not generally pollen limited.

This keeps colonization / establishment filtering alive. It also prevents a retrospective rule in which every evolved island difference is automatically attributed to the currently observed pollinator environment.

## Why Guaiacum matters

*Guaiacum* is useful because it prevents overfitting the whole story to reproductive assurance.

- Guánica and Mona differ strongly in visitor richness/composition and visitation rate.
- Guánica is overwhelmingly *Apis*-dominated.
- Autogamy is negligible in both populations.
- The reported self/outcross seed-set index is similar.

Possible explanations include compensatory abundance, service redundancy, unmeasured effectiveness or a plant-side state that is insensitive to this exposure contrast. The current source cannot distinguish those alternatives.

That uncertainty is a result: it tells us exactly which measurement is missing.

## Current causal decomposition

The best current architecture is now:

```text
PRE-EXISTING STATE
functional / access position
        |
        v
BRANCH POTENTIAL
        |
        +--- local plant/pollinator support
        +--- network rewiring / context
        +--- partner effectiveness
        |
        v
REALIZED INTERACTION / SERVICE
        |
        +--- reproductive dependency / assurance
        +--- resource compensation
        +--- service redundancy / compensatory abundance
        +--- establishment / survivorship filtering
        +--- other plant-side buffering
        |
        v
FINAL REPRODUCTIVE / FLORAL RESPONSE
```

No single observed downstream filter explains all current cases. The identity of the propagation gate is therefore system-specific or still unresolved.

### 2. Ogasawara Psychotria

The highest-value addition would be standardized per-visit pollen deposition/effectiveness by visitor × floral morph together with controlled pollinator exclusion/dependency. Numeric access position should enter only if measured prospectively or recovered source-natively; it must not be manufactured from secondary trait values.

### 3. Hawaii lobelioids

A controlled reproductive-dependency/assurance experiment in the same focal populations/seasons as the interaction-quality measurements would distinguish low dependency from post-interaction resource compensation.

### 4. Guaiacum

If source-native data become available, same-tree single-visit effectiveness plus a numeric open/outcross dependency estimand would discriminate *Apis* abundance compensation from visitor-diversity effects.

## Consequence for the paper

The central contribution is no longer a claim that islands cause one pollination syndrome. It is a **mechanistic explanation programme for why comparable upstream perturbations produce different downstream states**.

The empirical systems now contain at least four qualitatively distinct outcomes—propagation, buffering, branching and counterdirectional response—and the ABM work has already eliminated several simple explanations rather than merely reproducing a desired pattern.

That is a stronger novelty position than a literature synthesis alone.

## Claim boundary

The table identifies candidate discriminators, not hidden causal variables. `Resource compensation`, `service redundancy`, `establishment filtering` and similar labels remain hypotheses wherever the source does not isolate them experimentally. No cross-system causal coefficient is estimated, and the evidence does not identify one universal buffering mechanism.
