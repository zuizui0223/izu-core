# Chapter 1 isolation axis → Model 3 connectivity channels

Updated: 2026-09-27
Status: post-hoc bridge audit of the already frozen Model 3 connectivity factorial; no parameter retuning.

## Question

Chapter 1 uses geographic isolation as a broad macroecological coordinate. What biological processes can that single coordinate compress?

Model 3 independently varies seed-arrival distance and visitor-arrival distance over `0, 1, 3` model dispersal scales. The 3 × 3 factorial therefore provides a direct mechanistic decomposition of a broad isolation concept into plant and pollinator connectivity channels.

## Pollinator isolation has a repeatable direction in the frozen factorial

Holding seed distance fixed, increasing visitor distance from 0 to 3 changes mean inherited floral investment by:

- seed distance 0: `-0.21145`;
- seed distance 1: `-0.20065`;
- seed distance 3: `-0.17282`.

At the same time, realized selfing increases by:

- seed distance 0: `+0.44484`;
- seed distance 1: `+0.44480`;
- seed distance 3: `+0.44030`.

Thus, across all three seed-connectivity backgrounds in this frozen design:

> **lower pollinator connectivity shifts floral investment downward and realized selfing upward.**

This provides a direct Model 3 analogue of the Chapter 1 combination `stronger pollination constraint + recurrent reproductive assurance`.

## Seed isolation is not the same process

Holding visitor distance fixed, increasing seed distance from 0 to 3 changes investment by:

- visitor distance 0: `+0.01685`;
- visitor distance 1: `+0.01885`;
- visitor distance 3: `+0.05548`.

Founder ancestry changes by:

- visitor distance 0: `+0.19595`;
- visitor distance 1: `+0.29122`;
- visitor distance 3: `+0.35170`.

In this design, reduced seed connectivity therefore increases retention of founder ancestry and shifts floral investment upward or makes its decline weaker. This effect is not labelled 'gene flow causation' because seed immigration also changes demography and ancestry composition.

## Why this matters for Chapter 1

A single geographic distance can simultaneously imply:

```text
greater pollinator isolation
    -> reduced pollinator arrival / altered reproductive environment
    -> selfing rises
    -> floral-investment trajectory shifts downward in this baseline

greater plant/seed isolation
    -> reduced immigrant demographic/genetic input
    -> founder ancestry retained
    -> floral-investment trajectory shifts in a different direction
```

Therefore geographic isolation is not expected to map monotonically onto every floral phenotype even if one functional response, such as reproductive assurance, recurs.

## Connection to the Chapter 1 result

Chapter 1 finds:

1. pollen limitation increases with isolation;
2. reproductive assurance recurs;
3. detailed colour/architecture responses are regionally non-uniform.

The frozen Model 3 factorial supplies a coherent mechanistic interpretation:

> **The pollinator-connectivity component of isolation can repeatedly increase reliance on selfing, while the phenotype ultimately observed is additionally shaped by plant/seed connectivity, starting floral state, visitor functional composition and demographic history.**

This makes the Chapter 1 combination of a recurrent functional core and non-uniform detailed phenotype less paradoxical.

## What this audit does not show

- Model distance is in standardized dispersal scales, not kilometres.
- The 3 × 3 pattern is a post-hoc synthesis of a prospectively declared factorial, not a new preregistered directional hypothesis.
- Seed-distance effects are not identified as genetic gene flow alone.
- Floral investment is not literal flower colour, nectar guide strength or tube length.
- The four Chapter 1 geographic strata are not assigned to the nine Model 3 cells.

## Thesis-level implication

> **Isolation should be treated as a bundle of connectivity channels. A recurrent syndrome can emerge through the channel that repeatedly limits pollination, while other connectivity and historical channels prevent detailed phenotypic convergence.**
