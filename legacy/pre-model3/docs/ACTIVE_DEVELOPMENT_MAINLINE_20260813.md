## Current primary question

> Why does island-associated simplification or reorganization of pollinator function produce divergent plant responses rather than one universal post-establishment trajectory?

The ecological hypothesis is that the same broad perturbation can generate different outcomes because lineages enter it from different functional starting states and because local interaction context changes how the perturbation propagates downstream.

External island systems are comparative held-out response-state challenges. They do not choose seeds, parameters or mechanisms.

## H1–H5 recovery state

### H1 — universal post-establishment response

**Rejected.** A common frozen perturbation produces mixed-sign branching in 0.4167 of matched runs in both the original and independent blocks. Therefore one common island-like pollinator perturbation does not force one lineage response direction.

This does not reject macroecological island syndromes generated by colonization, establishment or persistence filtering.

### H2 — state-dependent branching

**Supported inside the declared ABM and independently replicated.** Removing initial functional-position heterogeneity changes mixed-sign branching from 0.4167 to 0 in both frozen blocks; other tested residual single-factor removals retain branching.

### H3 — context-dependent branch allocation

**Supported bidirectionally.** Local support changes 105/288 paired lineage signs. Network context yields 16/96 sign rescues, 85/96 magnitude attenuations and 11/96 worsenings.

Network context is a branch allocator with buffering capacity, not universal protection.

### H4 — autonomous-assurance buffering

**Partially supported and narrowed.** Assurance attenuates 207/216 independent declines but produces 0/216 sign rescues and 0/525 across the broadened envelope.

The stable claim is magnitude attenuation, not robust sign reversal.

### H5 — cross-island recurrence

**Supported at the qualitative state level.** The 13 strict systems comprise three branching, six same-direction propagation, two buffering/alternative, one reproductive-axis-decoupling constraint and one retained falsification. All 11 generative challenges are covered or sign-compatible with response classes already present in the frozen ABM.

This is recurrence of response architecture, not evidence that one empirical mechanism operates in all 13 systems.

## Ecological synthesis

The paper argues for a **state-dependent island-response view**:

```text
island-associated pollinator functional simplification / reorganization
        -> lineage-specific functional starting state
        -> branching or same-direction response
        -> local context reallocates / rescues / worsens branches
        -> reproductive filters attenuate downstream consequences
```

This is not a claim that classic island syndromes are wrong. Macroecological syndromes can arise from colonization filtering, differential persistence and aggregation across lineages. The present study addresses the post-establishment ecological response: an aggregate island syndrome does not imply that every established lineage follows the same trajectory.

## Role of state separability

State-separability analysis remains in the repository, but it is a **supporting inference guard**, not the paper's primary novelty. It is used to prevent overinterpretation of response labels:

- same-direction response does not prove uniform starting states;
- attenuation does not uniquely identify assurance versus network context;
- external state compatibility does not identify the real-world causal mechanism.

Detailed sensitivity/specificity diagnostics belong mainly to Supplementary material. The heading `The inverse problem is the main methodological result` must not survive in the primary island-ecology Discussion.

## Protected boundaries

- Guaiacum remains reproductive-axis decoupling, not whole-reproduction buffering.
- Dominica Heliconia remains a failed frozen signed-position projection and must not be retuned.
- Network context must not be called universally protective.
- Assurance must not be called a robust sign-rescue mechanism.
- The 13-system comparison must not be described as evidence that one empirical mechanism explains all islands.

## Unresolved sidelines — preserved but non-blocking

The primary scientific hypotheses are closed for submission. Three empirical translation questions remain valuable for the next programme:

1. **Real signed functional starting position:** identify the empirical plant–pollinator functional axis corresponding to the synthetic starting position using an outcome-blind mapping.
2. **Real network-context mechanism:** link local partner context to rate-weighted effective service and downstream reproductive response on matched units.
3. **Complete external causal bridge:** recover one independent system linking pollinator functional change -> effective service -> dependency/assurance -> downstream response.

These are future tests. They do not require new simulation, field data or external-system search before submission of the current paper.

Starting-state morphology recurrence remains supporting only because measurement-error/EIV requirements prevent formal promotion. Colonization-filter partitioning is a new hierarchical research question. Formal cross-system effect-size pooling remains closed because the current estimands are noncommensurate.
