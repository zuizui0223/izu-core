## Why raw and corrected trait matching must be separated

The source study defines raw species-level trait matching as an interaction-frequency
weighted proboscis–corolla-tube mismatch. Higher raw `TM_sp` therefore directly means
better realized morphological matching.

The source study then randomizes the plant-pollinator interaction matrix 10,000 times
while preserving marginal sums and expresses observed matching relative to that null.
Its species-level inferential response is this null-corrected `TM_sp_z`, specifically to
reduce the influence of background plant and pollinator community composition.

Consequently:

- raw `TM_sp` is an appropriate descriptor of **realized functional geometry**;
- `TM_sp_z` asks the stricter question of **non-random matching beyond the background
  community / marginal-composition expectation**.

The two estimands are not interchangeable.

## Result 1 — PR #300 raw geometry is exactly reproduced

For the frozen predictor

```text
predicted_matching_change
  = abs(initial_signed_position)
    - abs(initial_signed_position - island_center_shift)
```

and the predeclared model

```text
delta_TM_sp_raw ~ predicted_matching_change + island fixed effects
```

plant-cluster-robust inference gives:

- slope `+0.5669042695`;
- SE `0.1316146793`;
- cluster df `29`;
- two-sided `p = 0.000172711`;
- one-sided positive `p = 0.0000863553`;
- 95% CI `+0.297722` to `+0.836087`;
- Pearson `r = 0.570087`;
- Spearman `rho = 0.526933`;
- sign concordance `63/83 = 0.7590`.

This reproduces PR #300 rather than replacing it.

## Result 2 — correct plant starting-state identity matters

A fixed-seed 10,000-draw null permutes initial source positions among plant identities,
while preserving each plant's island coverage and observed target responses. The full
frozen geometric predictor is recomputed after every draw.

Raw target:

- observed slope `+0.566904`;
- null mean `-0.000442`;
- null SD `0.174318`;
- null 95th percentile `+0.290615`;
- null 99th percentile `+0.391558`;
- null 99.9th percentile `+0.500182`;
- `0/10,000` null slopes reach the observed slope;
- empirical one-sided `p = 1/10001 = 0.00009999`.

Therefore the raw result is not a generic island-fixed-effect pattern. The correct plant
source-state assignment carries real information.

## Result 3 — exact island-center magnitudes are not uniquely identified

All `5! = 120` assignments of the five observed island center shifts to island labels
were enumerated while plant starting positions and targets were held fixed.

Raw target:

- real-assignment slope `+0.566904`;
- permutation range `+0.413293` to `+0.607778`;
- median `+0.482107`;
- `13/120` assignments are at least as large as the real assignment;
- exact one-sided fraction `0.10833`.

Thus the data support a broad common directional shift in pollinator functional
composition, but do not identify the exact five island-specific center magnitudes/order
as uniquely necessary.

## Result 4 — source starting state alone describes raw change at least as well

Using the same 83 rows and island fixed effects:

```text
delta_TM_sp_raw ~ initial_signed_position + island fixed effects
```

where `initial_signed_position` differs from source tube only by the fixed continental
center, gives:

- slope `-0.203295`;
- SE `0.0454485`;
- `R² = 0.409056`;
- AIC `362.109`.

The full center-shift geometry gives:

- `R² = 0.364938`;
- AIC `368.085`.

The raw response therefore contains very strong **starting floral state** structure; the
precise island center shift does not add clear identification beyond that structure.

## Result 5 — the source-paper null-corrected target is unsupported

Keeping the exact same frozen predictor and rows, but replacing raw change with the
source-paper corrected response:

```text
delta_TM_sp_z ~ predicted_matching_change + island fixed effects
```

gives:

- slope `+0.0332847`;
- SE `0.1473150`;
- cluster df `29`;
- two-sided `p = 0.822831`;
- one-sided positive `p = 0.411416`;
- 95% CI `-0.268008` to `+0.334578`;
- Pearson `r = 0.0608683`;
- Spearman `rho = 0.0990822`;
- sign concordance `42/83 = 0.5060`.

Plant-position permutation for corrected matching:

- null mean `+0.001417`;
- null SD `0.126893`;
- `3918/10,000` null slopes >= observed;
- empirical one-sided `p = 0.391861`.

Source-position-only corrected model is also unsupported:

- slope `-0.0375894`;
- SE `0.0470113`;
- two-sided `p = 0.430454`.

There is therefore no evidence here that the frozen signed-position predictor explains
non-random partner matching **beyond background community composition**.

## Integrated interpretation

The defensible hierarchy is now:

```text
source floral starting state
  × broad shift toward shorter-tongued island pollinator communities
  -> realized raw matching geometry                 supported

exact island-specific center magnitudes / ordering
  -> additional identification                     weak / non-unique

signed source position
  -> null-corrected non-random partner sorting      unsupported
```

This does **not** make the PR #300 raw result meaningless or tautological. Raw `TM_sp`
is a real source-defined description of realized functional matching, and its association
requires the correct plant starting-state assignment. The stricter audit shows where the
information resides: primarily in source floral state and community composition rather
than an identified beyond-composition interaction-sorting process.

## Connection to `island` Chapter 1

This decomposition converges with `island` PR #139:

```text
isolation / source state
  -> region-specific lineage and community assembly
  -> realized floral-functional composition / matching geometry
```

The current evidence does not require an additional large within-lineage or
beyond-composition pollinator-selection component to explain the observed pattern.

That is an assembly-first synthesis, not evidence that pollinators are biologically
irrelevant. Pollinator processes can still act by filtering whole lineages and changing
community composition.

## Claim ceiling

This audit does not identify:

- historical Bombus loss;
- plant-specific partner-weighted functional centers;
- non-random pollinator choice or effectiveness;
- causal floral evolution;
- signed-position effects on single-visit pollen deposition;
- signed-position effects on fruit or seed output;
- independent held-out validation.

The next decisive empirical gate remains prospective Issue #91:

```text
visitor identity + exact/new proboscis + plant-specific visitor weights
  -> frozen plant-specific signed position
  -> single-visit pollen deposition
  -> direct reproductive dependency / mature seed outcome
```
