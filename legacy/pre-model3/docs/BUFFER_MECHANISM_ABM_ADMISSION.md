# Buffer-mechanism ABM admission

## Why this gate exists

The strict multi-system validation already showed that the frozen ABM can generate within-environment lineage branching and can produce directional response classes, but it does **not** yet contain a source-identified mechanism for the Hawaiʻi / Guaiacum / Nicotiana buffering classes.

That gap must not be filled by adding a free `buffer` parameter after seeing the observed outcomes.

`data/design/buffer_mechanism_abm_admission_interface.json` therefore freezes a common admission rule for any island system.

## Four distinct states

1. `candidate_only_no_abm_admission`
   - a source-supported mechanism candidate exists;
   - one or more matched evidence or mapping requirements are missing;
   - no empirical ABM parameter is admitted.

2. `mapping_ready_for_heldout_test`
   - upstream functional change, propagation/service, reproduction and the candidate filter are directly measured in matched units;
   - the sampling hierarchy and units are locked;
   - the ABM mapping is frozen before the target outcome test;
   - the target outcome was not used to choose parameter values.

3. `failed_predeclared_test_no_admission`
   - a mapping-ready mechanism failed its frozen held-out/prospective test;
   - the failure is retained;
   - retuning on the same target is forbidden.

4. `empirically_supported_mechanism_admission`
   - the frozen held-out/prospective test passed after all structural requirements were satisfied;
   - admission applies only to the declared mechanism and scope, not as a universal island law.

## Candidate mechanisms currently recognized

- autonomous reproductive assurance;
- service redundancy / compensatory abundance;
- resource or demographic compensation;
- colonization or establishment filtering;
- network context / rewiring.

The first, second and fifth already have conceptual homes in the current ABM. Resource/demographic compensation would require a **new component**, but only after passing the same admission gate. A new component cannot be justified merely because the present ABM lacks a buffering state.

## Hawaiʻi as the first real candidate package

The current Hawaiʻi package is intentionally encoded as:

`candidate_only_no_abm_admission`.

Why:

- 2026 sources contain signed functional matching, interaction-quality change and a reproductive-resilience boundary;
- named historical sources support autonomous assurance for exact focal `Clermontia lindseyana` and `C. pyrularia`;
- those historical measurements are not the same tagged 2026 plants/season;
- the 2026 same-context numeric dependency estimand is missing;
- `Cyanea shipmanii` is not covered by an exact matched historical dependency source.

So autonomous assurance is now a **real candidate**, not a generic story, but fitting the 2026 outcome with an assurance parameter would still be post hoc.

## Cross-system prediction ledger

`data/design/cross_system_buffer_prediction_ledger.json` freezes the signatures that would distinguish assurance, service redundancy, resource compensation, establishment filtering and network-context explanations.

The ledger deliberately includes contradictions:

- `Guaiacum` argues against autonomous assurance as a universal buffer because autogamy is negligible;
- `Nicotiana` keeps establishment filtering live because trait/assurance differences occur without a detected current service deficit;
- `Ogasawara Psychotria` is a propagation reference rather than a buffering example;
- `Dominica Heliconia` remains a failed frozen prediction and cannot be used as a model-rescue target.

## What happens when new data arrive

Create a candidate evidence package with the required fields, then run:

```bash
python scripts/audit_buffer_mechanism_abm_admission.py \
  --candidate path/to/candidate.json \
  --output path/to/admission.json
```

A result of `mapping_ready_for_heldout_test` means only that the mechanism may now be tested. It is **not** empirical support.

## Claim boundary

This interface does not estimate a parameter, identify a universal buffer, or make island systems quantitatively interchangeable. Its purpose is to make future mechanism additions falsifiable and to prevent outcome-dependent model growth.
