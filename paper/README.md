## Active Chapter 2 paper

The current Chapter 2 paper is complete as **simulation + source-audited metadata / secondary-data confrontation**:

`conditional response geometry → exact realized-richness control → finite-community/system-size determinant hierarchy → downstream modifiers → metadata confrontation → bounded empirical claim ceiling`

The key mechanism result is that determinant ordering is regime dependent. Community realization dominates in small stochastic communities, while starting position becomes the larger additive component in the larger finite-community regime under active plant adjustment. The declared numerical crossover is model-specific and is not transferred to nature.

Exact realized-richness matching changes the ensemble mean regime without removing individual response branching, and the deterministic mean-field limit removes branching only when finite realized composition is averaged away.
