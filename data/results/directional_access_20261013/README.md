# Directional investment-access evidence

Retrospective diagnosis of the original 2,304 histories, not a new biological cohort. Full census support arrays and case memberships are retained here. Independent verification reads the archived genomes and parent records without importing the producer or advancing the model.

Original raw ZIP: https://github.com/zuizui0223/izu-core/releases/download/four-question-resolution-20261013/ecological_order_actual_github_38312090996.zip

Original ZIP SHA256: 819741aa4a9f5bc1aaf2dadddbd56b79d158fc9295d07fc3bffe362693fc056a. ORIGINAL_COMPACT.json retains Git blob 5608ad2cdcbef167fe9062ab5f26318abf2e1bd9. Source/protocol were published before time extraction in DIRECTIONAL_ACCESS_PROTOCOL_SOURCE_20261013.zip (SHA256 250768dd25414d93258c7824a2efb66dbca613c9b7e9ecb3cebfeb95fe25240c).

From the repository root, after retrieving the original ZIP as raw.zip:

```text
python scripts/directional_access_20261013/verify_access.py --outer raw.zip --compact data/results/directional_access_20261013/ORIGINAL_COMPACT.json --output data/results/directional_access_20261013 --frozen scripts/directional_access_20261013/FROZEN_SOURCES.json --receipt fresh_review.json
```

The receipt path must not already exist. Verification requires NumPy and the original raw ZIP; no biological simulation is run. The saved independent receipt covers all 2,304 cases, 2,315,520 census-descriptor checks and 44,236,800 parent-homolog checks. Loss excludes only the founder-relative 0.05 decrease under the same no-I-mutation/no-immigration law. It does not attribute allele loss to selection versus drift, establish a natural-order benefit, or exclude every smaller investment decline.
